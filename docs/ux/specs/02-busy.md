# 02. 가림막 줄이기

상태: 02a 끝 (#426) · 02b 끝 (#431) · 02c 끝 (#454 · #PRNUM) · 계획: [plan.md](../plan.md) 의 02a · 02b번 · 먼저: 02b 는 02a

## 목표

02a: 저장 · 지우기처럼 곧 끝나는 동작은 화면이 어두워지지 않는다. 오래 걸릴 때만 가림막이 뜬다.
02b: AI 제안을 기다리는 동안 다른 칸을 읽고 고칠 수 있다. 답이 오면 알림과 함께 제안 칸이 채워진다.
README 관찰 라 · 마.

## 정할 것

1. 가림막을 늦추는 시간 — 추천: 400ms.
   - 400ms 안에 끝나면 가림막을 그리지 않는다.
   - 늦추는 동안에도 `#app` 의 `inert` 는 바로 건다. 두 번 누르기 · 저장 중 입력을 막는 지금 동작을 지킨다.
   - 늦추는 동안 누른 버튼에는 `aria-busy` 와 작은 돌림표를 단다.
2. 02b 로 옮길 호출 — 추천: `run('… 제안 만드는 중')` 꼴과 AI 를 부르는 `run` 을 모두 센 뒤 고른다.
   - 2026-11-09 에 센 후보: 신체 프로필 제안, 처음 수치 제안, 서술 말투 초안, 외형 태그, 새 인물 만들기, 꾸미기 안, 지도 설정 고르기, 문체 예시 쓰기, 정착 문체 재기, 갈래 만들기 등 20여 곳.
   - AI 를 부르지 않는 '다시 채점하는 중 · AI 없음' 같은 호출은 옮기지 않는다.
   - 2026-11-09 #431 이 인물 · 상태창 · 이름 · 문체 8곳을 옮겼다. 남은 15곳(대화 패널 빼고)은 02c 이고, 목록은 #431 본문의 '남은 AI 호출' 표다.
   - 대화 패널(`chat/{topic}`)과 `fix-now` 는 04 가 다룬다.
3. 옮긴 작업의 결과 자리 — 추천: 지금 결과를 놓는 칸에 그대로 놓는다. 작가가 그사이 다른 화면으로 갔으면 알림의 '가서 보기'로 돌아온다(`toast` 의 지금 동작).
4. 옮긴 작업이 도는 동안 같은 버튼 — 추천: `jobBtn` 처럼 '만드는 중' 으로 잠근다. 같은 제안을 두 번 띄우지 않는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/app.js` | `run`: 가림막 늦추기(02a). `opt.now` 로 바로 띄우기를 남긴다 |
| `canon/static/app.css` | 늦추는 동안 누른 버튼의 돌림표 |
| 02b 대상 화면 파일 (`cast.js` · `statwin.js` · `setup.js` · `style.js` · `atlas.js` 등) | `run` 대신 작업 시작(`startJob` 꼴)과 `JOB_PAGES` 등록 |
| `canon/routes/*.py` · `canon/jobs.py` | 02b 대상 호출을 작업으로 돌리는 엔드포인트. 지금 동기 엔드포인트가 있으면 작업 엔드포인트를 더하고 옛것은 명령줄 · 시험이 쓰는 동안 남긴다 |

- 작업 스레드는 `contextvars.copy_context()` 로 작품 · 화 정보를 넘긴다(AGENTS.md).
- LLM 호출은 지금처럼 `get_llm(단계)` 뒤에 둔다.

## 규칙

- AI 제안은 지금처럼 작가가 '적용'해야 데이터에 들어간다. 작업으로 옮겨도 바로 저장하지 않는다.
- 작업이 끝났을 때 작가가 그 칸을 고치는 중이면(`isTyping`) 칸을 다시 그리지 않고 알림만 띄운다.
