## 목표

AI 제품마다 붙는 상투 기호와 판에 박힌 예시가 화면에서 빠진다.
AI 를 부르는 버튼은 다른 버튼과 같은 말투(동사)로 무엇을 하는지만 말한다.
README 관찰 거 · 너.

- 대화 패널마다 예시 알약이 있다(`stylechat.js` 의 `examples`, 설정 · 플롯 대화의 예시). 작품 내용과 상관없이 늘 같다.

## 정할 것

1. ✦ — 추천: 모두 뺀다. AI 를 부른다는 것은 버튼 글(`AI 제안 받기`, `이름 후보 뽑기`)이 이미 말한다(`docs/design/README.md` 의 버튼 문구 규칙).
   - 대안: 디자인 시스템에 'AI 표시' 기호 하나를 정식으로 정하고 한 가지 뜻으로만 쓴다. 이 경우 기호는 ✦ 가 아닌 Canon 고유의 것으로 고른다.
2. 예시 알약 — 추천: 빈 대화에서만, 그 작품의 데이터로 만든 예시를 둘까지 보인다(예: 인물 이름, 지금 화 번호를 넣은 요청). 데이터가 없으면 예시를 두지 않고 입력칸 예시 글 하나만 둔다.
   - 예시를 만드는 데 AI 를 부르지 않는다. 틀 문장에 작품 값을 채운다.
3. 그 밖의 상투 꼴 — 추천: 같은 PR 에서 찾아 목록으로 적고 뺀다. 찾을 것: '마법' · '스마트' 같은 말, 반짝 애니메이션, 무지개 그라데이션, 버튼 안 이모지.
