## 정할 것

1. 실험 묶음 — 추천: 작품 안 사이드바에서 빼고 작품 밖 도구(작품 목록 사이드바)로 옮긴다. 작품 안에서는 찾기 팔레트로 부른다.
   - 연구 · 모델 실험, 큐 시트 집필 실험, 역설계 실험, 쇠맛 실험실, 사용량 · 비용이 대상이다. 사용량 · 비용은 이미 작품 밖에도 있다.
2. 아직 안 쓴 도구 — 추천: 사이드바에는 묶음 이름과 수만 두고(지금처럼 접힘), 펼침 상태를 기억하지 않는다(지금은 `canon.navMore` 에 기억한다).
   - 쓴 흔적이 있는 도구가 작품 도구로 올라오는 지금 규칙(`navItems` 가 돌려주는 도구 줄의 다섯째 값)은 그대로다.
3. 작품 홈 머리 — 추천: 주 버튼 하나(다음 할 일)와 `⋯` 메뉴 하나. 나머지 셋은 `⋯` 안으로 넣는다.
4. 설정 도우미 — 추천: 칸마다 붙은 AI 버튼(제안 받기 등)을 칸에 포커스가 있을 때나 칸 머리 `⋯` 에서 보인다. 버튼 수를 먼저 칸별로 세어 무엇을 숨길지 고른다.
5. 찾기 팔레트 — 추천: 사이드바에서 뺀 항목이 모두 팔레트에 나오는지 시험으로 지킨다.
