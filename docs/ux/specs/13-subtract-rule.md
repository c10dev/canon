# 13. 빼는 규칙

상태: 끝 (#463) · 계획: [plan.md](../plan.md) 의 13번 · 먼저: —

## 목표

새 기능이 화면에 문장 · 버튼 · 메뉴를 더할 때, 무엇을 빼거나 숨길지도 함께 정한다.
에이전트 세션이 PR 을 낼 때 이 규칙을 따른다.
README 관찰 버. 코드 동작은 바뀌지 않는다(규칙 문서 일감).

## 지금 (2026-11-09)

- 첫 커밋 2026-10-22, 18일 동안 커밋 808개, 하루 최대 109개(10-27).
- 화면 JS 71개, 작품 안 사이드바 항목 35개, 설정 도우미 버튼 121개.
- `docs/design/README.md` 는 색 · 글자 · 간격 · 문구 꼴을 정하지만 화면에 무엇을 두지 않을지는 정하지 않는다.

## 정할 것

1. 규칙 — 추천: `docs/design/README.md` 에 '덜기' 절을 둔다.
   - 한 화면의 늘 보이는 안내 문장은 다섯 개를 넘지 않는다(09 의 세기 스크립트로 잰다).
   - 정함(2026-11-09, 사용자): 안내 문장은 세 개 이하, 주 버튼은 하나다.
   - 한 화면의 `main` 안 먹색 주 버튼은 하나다(11 의 시험).
   - 새 기능이 늘 보이는 버튼이나 안내 문장을 더하면, PR 에 그 화면의 전후 수를 적는다. 상한을 넘으면 다른 것을 접거나 뺀다.
   - 새 화면 · 도구는 사이드바 대신 찾기 팔레트에 먼저 둔다. 쓴 흔적이 생기면 사이드바에 오른다(07 의 규칙).
2. 지키는 곳 — 추천: AGENTS.md 의 '규칙' 절에 한 줄로 가리키고(화면에 요소를 더하면 `docs/design/README.md` 의 '덜기' 절을 따른다), 세는 시험은 09 · 11 이 만든 것을 쓴다.
3. 이미 넘은 화면 — 추천: 규칙이 들어온 날의 수를 기준 표로 남기고, 그 수보다 늘지 않게만 막는다. 줄이는 일은 07 · 09 · 11 · 12 가 한다.
