# 12. 숫자와 빈 칸 접기

상태: 끝 (#434) · 계획: [plan.md](../plan.md) 의 12번 · 먼저: —

## 목표

작가가 판단에 쓰기 어려운 지표와 비어 있는 칸이 늘 펼쳐져 있지 않다.
값이 있는 것과 작가가 고칠 것이 먼저 보인다.
README 관찰 머.

## 지금 (2026-11-09, 데모 작품)

- 문체 레퍼런스 맨 위에 지표 칩 11개가 있다: 문장 평균, 길이 변화폭, 문단 평균, 대사 비율, 과거형, 어휘 다양도, 쉼표 문장, 물결표 대사, 대사 길이, 효과음 줄, 말버릇. 값이 없는 칩은 '-' 로 보인다.
- 서술 표는 열한 줄 중 일곱 줄이 "비어 있음" 이다.

## 정할 것

1. 지표 칩 — 추천: 맨 위에는 레퍼런스와 가장 어긋난 지표 둘(또는 경고가 난 지표)만 한 줄 글로 보인다("대사가 레퍼런스보다 짧아요"). 나머지는 '지표 풀이' 를 열면 보인다. 값이 없는 지표는 칩을 그리지 않는다.
2. 빈 줄 — 추천: 값이 있는 줄만 보이고, 빈 줄은 '빈 칸 7개 채우기' 버튼 하나로 묶는다. 누르면 펼친다.
3. 같은 꼴의 다른 화면 — 추천: 같은 PR 에서 '-' · '비어 있음' · '0' 을 늘 펼쳐 보이는 화면을 세어 목록으로 적고, 고칠 화면은 사용자와 고른다. 후보: 상태창 수치, 인물 신체 프로필, 작품 홈 '확인할 것'.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/style.js` · `mystyle.js` | 지표 칩 요약, 빈 줄 묶기 |
| `canon/static/app.css` | 묶음 버튼 |
| `docs/design/README.md` 또는 `components/Table/` | 빈 값을 보이는 규칙 |

## 시험

- 지표 요약 순수 함수의 JS 시험: 가장 어긋난 둘을 고르는지, 값 없는 지표를 빼는지.
- 빈 줄 묶기 JS 시험.
- 문체 화면 기존 시험이 그대로 통과하는지.

## 문서

- `docs/modules/web.md` 의 `canon/static/style.js` 절.
- `docs/design/` 의 빈 값 규칙.
