# 쓰는 흐름 작업 문서

Canon 웹 화면을 쓰는 동안 끊기는 곳을 고치는 일의 설계 자산이다.
화면 모양(색 · 글자 · 간격 · 컴포넌트)은 [docs/design/](../design/README.md) 이 원본이다. 이 폴더는 동작과 흐름을 다룬다.
2026-11-09 에 데모 작품 사본을 mock 으로 띄워 화면을 돌려 보고, Claude · ChatGPT · Orca · Novelcrafter · Sudowrite 와 견준 결과에서 일감을 뽑았다.
기능이 들어가면 동작 설명은 [docs/modules/web.md](../modules/web.md) 와 [DESIGN.md](../../DESIGN.md) 에 쓰고 이 폴더를 가리킨다. 이 폴더는 일을 나누고 이어 가는 데 쓴다.

|---|---|---|

| [plan.md](plan.md) | 일감 차례, 먼저 끝날 것, 같이 할 수 있는 묶음, 장기 후보 | 다음 일을 고를 때 |

문제가 아니었던 것:

- 가만히 둔 10초 동안 다시 그리기와 서버 호출은 0번이었다.
- 데모 작품(10화)에서 화면 한 번 그리기는 5~11ms 였다. 끊김의 원인은 그리기 속도가 아니다.
- 다시 그린 뒤에도 스크롤 자리, 포커스, 본문 칸의 커서 위치는 돌아온다.

## 'AI 가 찍어 낸 화면' 같은 인상 (2026-11-09)

사용자가 화면이 slop 처럼 느껴진다고 했다. 같은 mock 서버에서 화면 12개를 돌며 세고, 설정 도우미 · 문체 레퍼런스를 캡처해 봤다.
데모 작품의 자리표시 글("1화 제목", "1화 요약", 로그라인 "x", "(mock 본문)")은 이 인상을 키운다. 실제 작품 화면에서 다시 본다.

| # | 관찰 | 근거 | 일감 |
|---|---|---|---|
| 파 | 화면이 자기 작동법을 설명한다. 집필 화면 한 곳에 "드래그하거나 길게 눌러" 안내가 네 번 나온다 | 본문 칸 위, 삽화, 대화 패널 소개, 입력칸 위. '~요.' 로 끝나는 안내 문장이 설정 도우미 29개, 문체 26개 | [09](specs/09-copy-edit.md) |
| 하 | 안내 문장에 내부 용어와 규칙이 드러난다 | "스타일 프로필에서 바꿀 칸", "기준보다 30% 넘게 길면 경고해요", "정착 문체" | [09](specs/09-copy-edit.md) |

## 다른 프로그램과의 차이

| 기준 | Canon | 견준 프로그램 |
|---|---|---|
| AI 대화 | 화면마다 다른 대화 넷, 없는 화면도 있다 | Claude · ChatGPT 는 대화 하나가 어느 작업에서든 이어진다 |
| 답 보여 주기 | 끝나야 보인다, 짧은 작업은 화면을 막는다 | Claude · ChatGPT 는 답을 흘려 보인다. Orca 는 에이전트마다 터미널 출력이 실시간이다 |
| 부분 고치기 | 드래그 → 'AI에게 고치기', 후보 2~3개 | ChatGPT Canvas 도 고른 곳에 묻는다. Sudowrite Write Guided 는 방향 셋을 준다 |
| 되돌리기 · 버전 | 저장 단위 버전, 저장하면 Ctrl+Z 가 끊긴다 | ChatGPT Canvas 는 버전 보기 · 비교 · 복원을 준다. Orca 는 git diff · 커밋을 쓴다 |
| AI 변경 확인 | 상태 승인 화면(따로 있는 단계) | Orca 는 작업 옆에서 diff 를 보고 커밋한다 |
| 이야기 맥락 | 구조화 데이터로 자동 조립 | Novelcrafter Codex 는 이름을 보면 항목을 넣는다. Sudowrite Story Bible 은 쓰기 도구가 먼저 읽는다 |

## 원칙과의 경계

- AGENTS.md 의 설계 원칙은 그대로다. 이 폴더의 일감은 그 원칙을 느슨하게 하지 않는다.
- 상태 승인은 없애지 않는다. 일감 06 은 승인을 고르는 자리를 옮길 뿐, 작가가 고르기 전에는 데이터에 반영하지 않는다.
- 스트리밍(일감 05)도 `LLM` 인터페이스 뒤에 둔다. pipeline · cli 에서 SDK 를 바로 부르지 않고, `usage.record` 는 지금처럼 한 번 부른다.
- 대화 에이전트의 '어느 모드에서도 AI 가 하지 않는 일'은 바꾸지 않는다.
- 일감 04 가 에이전트에 새 쓰기 종류를 더할 때, 그 종류를 묻지 않고 쓰게 하는 기본값은 사용자와 정한다(AGENTS.md).
- Swift 앱은 고치지 않는다(AGENTS.md, 2026-10-28).
- 화면 모양을 바꾸는 일감은 같은 변경 안에서 `docs/design/` 을 고친다.

## 용어

- 가림막: `app.js` `run` 이 띄우는 `#busy` 층. 뒤 화면을 `inert` 로 막는다.
- 대화 패널: `chat.js` `chatPanel` 이 그리는 옆 칸(900px 이하는 아래 시트). 주제마다 다른 대화가 들어간다.
- 다시 그리기: `app.js` `render` → `drawApp`. `#app` 의 innerHTML 을 통째로 바꾼다.
