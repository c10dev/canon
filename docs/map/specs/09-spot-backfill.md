# 09. 옛 핀의 건물 한 줄 채우기

상태: 설계 · 계획: [plan.md](../plan.md) 의 9번 (차례 미정) · 먼저: PR [#140](https://github.com/c10dev/canon/pull/140)

## 목표

#140 이전에 놓은 핀에도 건물 한 줄(`MapPin.spot`)이 생겨, 쓰기 · 검수 프롬프트의 '장소가 놓인 건물' 블록이 바로 쓰인다. 지금은 지도를 한 번 고쳐야 줄이 생긴다.

## 정할 것

1. 언제 채우나 — 추천: 지도 화면을 열 때와 쓰기 · 검수 작업을 시작할 때 빈 `spot` 을 채운다. 지도 화면(GET)은 응답에만 싣고 `project.json` 을 쓰지 않는다. 작업 시작 때 채운 값은 그 작업이 작품을 저장할 때 함께 저장된다. 다른 안: 명령줄 `map <작품> spots` 로 한 번에 채운다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/web.py` | 지도 화면을 여는 `atlas_view` 에서 빈 `spot` 을 메모리에서 채워 응답에 싣는다. 저장은 다음 쓰기 요청 때 |
| `canon/web.py` · `canon/cli.py` · `canon/autorun.py` | 쓰기 · 검수 작업을 시작하는 곳(작품 폴더를 안다)에서 지도 파일이 있고 `spot` 이 빈 핀이 있으면 채운다. `pipeline` 은 작품 폴더를 모르므로 여기서 채운다 |

## 시험

- `spot` 이 빈 핀이 있는 작품으로 쓰기 프롬프트를 만들면 블록이 들어간다.
- 지도 화면 GET 이 `project.json` 을 바꾸지 않는다.
