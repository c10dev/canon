# 11. 지도 장식 (축척 · 나침반 · 제목 틀)

상태: 설계 · 계획: [plan.md](../plan.md) 의 11번 · 근거: [research-look.md](../research-look.md) 의 P1 · W1

## 목표

지도에 축척 막대 · 북쪽 화살표 · 제목 틀을 그려 '지도답게' 보이게 한다. 작가는 축척 막대로 장소 사이 거리를 지도 위에서 바로 가늠한다. 지도 데이터는 바뀌지 않는다.

## 정할 것

1. 놓는 자리 — 추천: 축척 막대와 북쪽 화살표는 오른쪽 아래 출처 글 위, 제목 틀은 왼쪽 위. 고르는 칸은 두지 않는다.
2. 겹 — 추천: 새 겹 '장식'(키 `d`) 하나로 셋을 함께 끄고 켠다. 지금 '이름' 겹(`title`)은 제목 틀이 대신하므로 '장식'으로 합칠지 시작할 때 본다.
3. 북쪽 — 추천: OSM 지도에만 북쪽 화살표를 그린다(북이 위). 생성기 지도는 정해진 북이 없어 화살표를 그리지 않는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/atlas.js` | `atlasSvg` 끝에 장식 그리기(화면 크기 고정, `sc` 로 배율 역수), `ATLAS_LAYERS` 에 '장식', 화풍별 CSS(`.at-v-frame`). 출처 글(`at-v-source`, `atlas.js:476`)을 틀 안으로 옮기되 지우지 않는다 |
| `canon/static/atlas-export.js` | 내보내기 제목 글(`atlas-export.js:50` 근처)을 제목 틀로 바꾼다. 내보낸 그림에도 축척 막대 · 출처를 그린다 |

## 지도 데이터

읽기만 한다: 축척은 `Atlas.meters`(1단위 m) 또는 `Atlas.span_km` · `layout_size`. 둘 다 모르면(배경 그림만, 모눈) 축척 막대를 그리지 않는다. 새 키 없음, `VERSION` 그대로.

## 규칙

- 축척 막대 길이는 화면 폭의 약 1/6 에 가까운 둥근 값(10 · 20 · 50 · 100 · 200 · 500 m, 1 · 2 · 5 km). 확대하면 값이 바뀐다.
- 제목 틀은 지도 이름(`Atlas.title`) · 인구 어림. 이름이 없으면 틀을 그리지 않는다(OSM 지도 이름을 파일에서 읽는 일은 research-look.md 4.1 절, 따로 정한다).
- OSM 출처 글은 장식을 꺼도 늘 그린다(README 2026-10-28). 빈 블록을 채운 지도의 긴 출처 글(`fill.FILLED_SOURCE`)이 들어갈 폭을 둔다.
- 장식은 장소 이름표가 비켜 가도록 `taken` 에 먼저 넣는다.

## 화면 · 명령줄 · 프롬프트

화면 문구 예: 겹 이름 '장식', 축척을 모를 때 옆 칸 안내 '지도 크기를 몰라 축척 막대를 그리지 않아요'. 프롬프트 · 명령줄은 바뀌지 않는다.

## 시험

- node 시험(`tests/test_atlas_js.py` 꼴): 축척 막대 둥근 값 고르기(배율 · 축척별), 축척을 모르면 빈 값.
- 브라우저: 마을 · 도시 · 현대 동네 · OSM 지도를 화풍 4종으로 보고, 좁은 화면(휴대폰 폭)에서 장식이 이름표 · 버튼을 가리지 않는지 본다.
- SVG · PNG 내보내기에 장식과 출처가 나오는지 본다.
