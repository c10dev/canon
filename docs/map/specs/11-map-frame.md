# 11. 지도 장식 (축척 · 나침반 · 제목 틀)

상태: 구현 · 계획: [plan.md](../plan.md) 의 11번 · 근거: [research-look.md](../research-look.md) 의 P1 · W1

## 목표

지도에 축척 막대 · 북쪽 화살표 · 제목 틀을 그려 '지도답게' 보이게 한다. 작가는 축척 막대로 장소 사이 거리를 지도 위에서 바로 가늠한다. 지도 데이터는 바뀌지 않는다.

## 정할 것

1. 놓는 자리 — 추천: 축척 막대와 북쪽 화살표는 오른쪽 아래 출처 글 위, 제목 틀은 왼쪽 위. 고르는 칸은 두지 않는다.
2. 겹 — 추천: 새 겹 '장식'(키 `d`) 하나로 셋을 함께 끄고 켠다. 지금 '이름' 겹(`title`)은 제목 틀이 대신하므로 '장식'으로 합칠지 시작할 때 본다.
3. 북쪽 — 추천: OSM 지도에만 북쪽 화살표를 그린다(북이 위). 생성기 지도는 정해진 북이 없어 화살표를 그리지 않는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/atlas.js` | `atlasSvg` 끝에 장식 그리기(화면 크기 고정, `sc` 로 배율 역수), `ATLAS_LAYERS` 에 '장식', 화풍별 CSS(`.at-v-frame`). 출처 글(`at-v-source`, `atlas.js:476`)을 틀 안으로 옮기되 지우지 않는다 |
| `canon/static/atlas-export.js` | 내보내기 제목 글(`atlas-export.js:50` 근처)을 제목 틀로 바꾼다. 내보낸 그림에도 축척 막대 · 출처를 그린다 |

## 지도 데이터

읽기만 한다: 축척은 `Atlas.meters`(1단위 m) 또는 `Atlas.span_km` · `layout_size`. 둘 다 모르면(배경 그림만, 모눈) 축척 막대를 그리지 않는다. 새 키 없음, `VERSION` 그대로.

## 규칙

- 축척 막대 길이는 화면 폭의 약 1/6 에 가까운 둥근 값(10 · 20 · 50 · 100 · 200 · 500 m, 1 · 2 · 5 km). 확대하면 값이 바뀐다.
- 제목 틀은 지도 이름(`Atlas.title`) · 인구 어림. 이름이 없으면 틀을 그리지 않는다(OSM 지도 이름을 파일에서 읽는 일은 research-look.md 4.1 절, 따로 정한다).
- OSM 출처 글은 장식을 꺼도 늘 그린다(README 2026-10-28). 빈 블록을 채운 지도의 긴 출처 글(`fill.FILLED_SOURCE`)이 들어갈 폭을 둔다.
- 장식은 장소 이름표가 비켜 가도록 `taken` 에 먼저 넣는다.

## 화면 · 명령줄 · 프롬프트

화면 문구 예: 겹 이름 '장식', 축척을 모를 때 옆 칸 안내 '지도 크기를 몰라 축척 막대를 그리지 않아요'. 프롬프트 · 명령줄은 바뀌지 않는다.

## 시험

- node 시험(`tests/test_atlas_js.py` 꼴): 축척 막대 둥근 값 고르기(배율 · 축척별), 축척을 모르면 빈 값.
- 브라우저: 마을 · 도시 · 현대 동네 · OSM 지도를 화풍 4종으로 보고, 좁은 화면(휴대폰 폭)에서 장식이 이름표 · 버튼을 가리지 않는지 본다.
- SVG · PNG 내보내기에 장식과 출처가 나오는지 본다.

장식이 '지도답게' 보이는지는 사용자 취향 판단이다. 스크린샷을 보내 확인받는다.

## 구현 메모

2026-10-29 구현.

- 겹: 옛 '이름' 겹(`title`, N)을 새 겹 '장식'(`deco`, D)에 합쳤다. 제목 틀이 옛 이름 상자를 대신해, 두 칸을 두면 같은 것을 두 칸이 끄고 켜기 때문이다. 옛 '이름' 겹을 끈 브라우저는 '장식'도 꺼진 채로 읽는다(`atlasLayersLoad`).
- 그리기: `atlasDeco` 가 지금 보는 범위의 모서리에 화면에서 같은 크기로 그린다(화면 1px 의 지도 단위 `u`). 이름표보다 먼저 상자를 `taken` 에 넣는다. `atlasLabels` 는 원래 `taken` 을 읽지 않아서, 먼저 들어 있는 상자도 비켜 가게 고쳤다. 그림은 인물 표 뒤, 맨 위에 그린다. 휴대폰 폭(지도 480px 아래)에서는 글자를 줄인다.
- 출처 글: `atlasVillageSvg` 끝(지도 오른쪽 아래 고정)에서 장식으로 옮겼다. 그래서 확대해도 화면 모서리에 보인다. 장식을 켜면 축척 막대 틀 안 아래 줄에, 끄면 틀 없이 글만 그린다. 보이는 폭보다 길면(빈 블록을 채운 지도 `FILLED_SOURCE`, 휴대폰 폭) 글자를 줄인다.
- 축척: `atlasScaleBar(m/단위, 배율, 폭)` 이 1 · 2 · 5 × 10ⁿ m(10m 부터) 가운데 보이는 폭 1/6 에 로그로 가장 가까운 값을 고른다. 명세의 목록(10m~5km)보다 위로도 이어진다(지도 가로 수십 km 배경 그림). 지도 단위의 m 는 `atlasMpu`: 미리보기 · 생성기 지도 1m, 올린 마을은 `layout.width_m`, 배경 그림 · 모눈은 이동 시간 검사의 지도 가로 km(`travel.scale`). 모르면 그리지 않고 배경 그림 칸에 '지도 크기를 몰라 축척 막대를 그리지 않아요'를 보인다.
- 제목 틀: SVG 라 화풍 색을 따르고 내보낸 그림에도 그대로 나온다. 누르거나 Enter 로 이름 고치는 칸을 연다. 이름이 없으면 틀을 그리지 않고, 화면에만 '마을 · 도시 · 동네 이름 정하기' 버튼(HTML)을 띄운다. 그 버튼이 없으면 이름을 정할 곳이 없다. 이름이 길면 보이는 폭의 60% 에서 '…'로 자른다. 글자 폭은 캔버스로 잰다(`atlasDecoW`).
- 내보내기: 손으로 넣던 제목 글(`atlas-export.js`)을 뺐다. 장식이 배율 1 로 함께 그려진다.
- 명세와 다르게 한 곳: 지도 만들기 미리보기 중에는 아래 막대(`.at-pv-bar`)가 오른쪽 아래를 덮어 축척 막대 · 북쪽 화살표를 그리지 않는다(제목 틀은 그린다). 배경 그림 · 모눈 지도에는 겹 칸이 없어 장식을 끄는 칸이 보이지 않는다(축척 막대는 지도 가로 km 를 적었을 때만 그린다).
- 확인: node 시험(`tests/test_atlas_js.py`: 축척 막대 값 · 축척 모름 · 장식 상자 비키기), mock 서버에서 마을 · 도시 · 현대 동네 · OSM 강남 · 해운대(빈 블록 채움)를 화풍 4종, 배율 1 · 4, 휴대폰 폭(390px)으로 찍었다. SVG · PNG 내보내기에 제목 틀 · 축척 막대 · 북쪽 화살표 · 출처 글이 나온다.
