# 13. 화풍을 따라가는 동선 · 핀

상태: 설계 · 계획: [plan.md](../plan.md) 의 13번 · 근거: [research-look.md](../research-look.md) 의 P3 · W4 · W5

## 목표

인물 동선과 핀이 화풍에 맞는 색 · 무늬로 그려지고, 길 색과 섞이지 않으며, 어느 방향 · 어느 화 순서로 옮겼는지 보인다. 지도 데이터는 바뀌지 않는다.

## 정할 것

1. 흑백 인쇄에서 인물 나누기 — 추천: 모두 검정 계열에 인물마다 다른 점선 무늬(`stroke-dasharray` 열 가지).
2. 화 번호 점 — 추천: 장소를 갈아탄 곳마다 작은 원 안에 화 번호. 배율이 낮아 겹치면 처음 · 끝만 남긴다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/atlas.js` | `ATLAS_COLORS`(`atlas.js:61`) · `atlasColor`(`atlas.js:495`)를 화풍별 CSS 변수(`--v-ink0` … `--v-ink9`)로, 동선(`atlas.js:592`)에 바깥 테두리(halo) · 방향 화살표(`<marker>` 를 `defs` 에) · 화 번호 점, `.at-trail`(`atlas.js:1923`)의 `opacity .6` 을 불투명으로 바꾸고 굵기를 키움, 옆 칸 인물 견본(`.at-who i`)도 같은 색 · 무늬 |
| `canon/static/atlas-export.js` | 내보내기가 `marker-*` · `stroke-dasharray` 를 속성으로 옮겨 적는지 확인하고 빠지면 더한다 |

## 지도 데이터

바뀌지 않는다. 동선은 `frames` · `row.route`(서버 응답)를 읽는다.

## 규칙

- 화풍별 잉크: 기본은 지금 열 색, 양피지는 적갈 · 남색 · 먹색 같은 잉크 열 색, 밤은 밝은 색, 흑백 인쇄는 검정 + 무늬.
- 같은 길을 가는 두 인물은 지금처럼 옆으로 조금 비켜 그린다(`off`).
- 화살표 · 화 번호 점은 배율이 낮으면 줄인다(도시 동선이 지저분하지 않게).

## 화면 · 명령줄 · 프롬프트

화면 문구는 바뀌지 않는다.

## 시험

- node 시험: 화 번호 점 고르기(겹치면 처음 · 끝만), 화풍별 잉크 이름 순서.
- 브라우저: 강남 · 마을 지도의 동선을 화풍 4종으로 보고 research-look.md 의 `*-print.png` · `zoom-gangnam.png` 와 견준다.
- SVG · PNG 내보내기에 화살표 · 점선이 나오는지 본다.
