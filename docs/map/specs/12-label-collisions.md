# 12. 이름표 충돌 보강

상태: 구현 · 계획: [plan.md](../plan.md) 의 12번 · 근거: [research-look.md](../research-look.md) 의 P2 · W2 · W3

## 목표

인물 표가 장소 이름을 덮지 않게 하고, 같은 구역 이름이 한 화면에 되풀이되지 않게 한다. 이야기 장소 이름이 늘 먼저 읽힌다. 지도 데이터는 바뀌지 않는다.

## 정할 것

1. 구역 이름 거르기 — 정함(2026-10-29, 사용자가 P2 를 고름): 길 이름표의 '같은 이름은 화면 폭 1/4 안에 하나'(README 2026-10-29) 규칙을 구역 이름에도 쓴다.
2. 인물 표와 장소 이름이 겹칠 때 — 정함(추천안): 인물 표 상자를 이름표보다 먼저 `taken` 에 넣어 장소 이름이 비켜 간다. 인물 표는 움직이지 않는다(인물 자리가 뜻이 있어서).

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/static/atlas.js` | 인물 표 상자를 `taken` 에 넣는 순서(`atlas.js:611` 근처), `atlasWardLabels`(`atlas.js:282`)가 `atlasLabelPick` 로 같은 이름 구역을 거름, 우선순위 주석 '이야기 장소 > 구역 > 길' |

## 지도 데이터

바뀌지 않는다. 구역은 `wards`(이름 · 다각형)를 읽는다.

## 규칙

- 놓는 차례: 인물 표 → 장소 이름표(`atlasLabels`) → 구역 이름 → 길 이름. 앞에 놓은 것이 이긴다.
- 구역 이름 자리는 지금처럼 넓이 가운데다. 같은 이름 구역은 넓은 것부터 본다.
- 확대하면 구역 이름이 더 자주 보여도 된다(화면 거리 기준).

## 화면 · 명령줄 · 프롬프트

화면 문구는 바뀌지 않는다.

## 시험

- node 시험: `atlasLabelPick` 을 구역 목록에 쓴 결과(가까운 같은 이름 셋 → 하나, 멀면 둘).
- `tests/test_atlas_js.py` 가 섹션 주석으로 자르는 구간(modules.md 6절)을 옮기면 시험도 함께 고친다.
- 브라우저: 도시 생성기 지도에서 '상인' · '빈민' 구역 이름 수, 현대 동네 기본 지도의 '수산시장' 이름표(research-look.md 스크린샷 `city-base.png` · `modern-base.png` 와 견줌).

## 문서

## 확인하지 못할 것

없음.

## 구현 메모

2026-10-29 구현.

- 놓는 차례: `atlasSvg` 가 인물 표 자리를 이름표보다 먼저 계산해(`atlasTokenAt`) 표 동그라미 상자를 장식 상자 뒤에 `taken` 에 넣는다. 그다음 장소 이름표(`atlasLabels`) → 구역 이름(`atlasWardLabels`) → 길 이름(`atlasStreetLabels`) 차례로 놓는다. 이 차례를 `atlasSvg` 주석에 적었다. 그리는 겹은 그대로다(구역 · 길 이름 → 장소 이름표 → 인물 표 → 장식).
- 구역 이름: `atlasWardPick` 이 구역 넓이를 길이 삼아 `atlasLabelPick` 에 넘긴다. 그래서 넓은 구역부터 보고, 같은 이름은 화면 폭의 1/4(지도 폭 ÷ 배율 ÷ 4) 안에 하나만 그린다. 자리가 없어 못 그린 구역은 가까운 같은 이름을 막지 않는다(길 이름과 같은 규칙).
- 명세와 다르게 한 곳: 시험이 섹션 주석으로 자르는 '되돌리기 · 따라가기 계산' 구간에 `atlasMid`(위에서 옮김) · `atlasArea` · `atlasWardPick` · `atlasTokenAt` 를 두었다. 시험이 이 함수를 그대로 부르게 하려는 것이다. 자르는 구간의 시작 · 끝 주석은 바꾸지 않았다.
- 현대 동네 생성기 지도의 슈퍼블록 이름(빌라촌 · 아파트 단지)도 같은 규칙을 따른다. 명세는 도시 구역만 말했지만 구역 이름 함수가 하나라 함께 줄어든다.
- 숫자(mock 서버, 화면 폭 1440px, 지도 칸): 도시 생성기(시드 11) 배율 1 에서 '상인' 14 → 3, '빈민' 5 → 2, '항구' 3 → 2, '귀족' 2 → 1. 현대 동네 생성기(시드 5) 배율 1 에서 '아파트 단지' 4 → 3, '빌라촌' 5 → 5(서로 멀다). 인물 표에 덮인 장소 이름표는 도시 '우물', 현대 동네 '수산시장' 하나씩에서 0 이 됐다. OSM 강남은 배율 1 · 4 모두 구역 이름이 없고 인물 표에 덮인 이름표도 전 · 뒤 0 이다.
- 남은 한계: `atlasLabels` 는 마흔 자리가 모두 막히면 마지막 자리에 겹쳐 둔다. 아주 붐비는 곳에서는 장소 이름표가 인물 표와 겹칠 수 있다.
- 확인: node 시험(`tests/test_atlas_js.py`: 가까운 같은 이름 구역 셋 → 넓은 하나, 멀면 따로, 확대하면 둘, 인물 표 상자를 먼저 넣으면 장소 이름표가 비켜 감).
