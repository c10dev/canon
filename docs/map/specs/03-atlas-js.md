# 03. `static/atlas.js` 나누기

상태: 설계 · 계획: [plan.md](../plan.md) 의 3번

## 목표

동작은 바뀌지 않는다. 2,454줄 지도 화면 파일(#140 뒤 2,554줄)을 다른 화면처럼 기능별 파일로 나눈다.

## 정할 것

1. 나누는 단위 — 정함(2026-10-28, 나누기): 아래 새 파일 다섯. 섹션 주석(`// -----`)을 경계로 쓴다.

## 바꿀 곳

| 새 파일 | 옮길 섹션 (지금 `atlas.js` 의 섹션 주석) |
|---|---|
| `atlas.js` | 상태 · 불러오기, 지도 그림, 되돌리기 · 따라가기 계산, 확대 · 이동 · 이름표, 옆 칸 조립, 저장, 장소 이동 되돌리기, 재생할 때 따라가기, 동작 중 공통 |
| `atlas-gen.js` | 지도 만들기 (`atlasGen*`) |
| `atlas-travel.js` | 이동 시간 검사 (`atlasTravel*`) |
| `atlas-table.js` | 장소와 맞지 않은 위치, 어디에 있었나 표 |
| `atlas-export.js` | 내보내기 |
| `atlas-find.js` | #140 의 이름으로 자리 찾기 (`atlasFind*`) |
| `canon/static/index.html` | `atlas.js` 바로 뒤에 새 파일들을 읽는다 |

각 파일은 다른 화면 파일처럼 `Object.assign(actions, {...})` 로 동작을 붙인다. 입력 바인딩(`change` · `input` 처리)은 기능 파일로 옮긴다.

## 지도 데이터

바뀌지 않는다.

## 규칙

- 함수 몸은 옮기기만 한다.
- 전역 이름은 그대로다. 다른 파일(`mentions.js` 등)이 부르는 지도 함수 이름을 바꾸지 않는다.

## 시험

- `tests/test_atlas_js.py` 는 `atlas.js` 를 섹션 주석으로 잘라 돌린다(`tests/test_atlas_js.py:16`, `:27`). 그 두 구간은 `atlas.js` 에 남기거나, 시험이 새 파일을 읽게 고친다.
- 브라우저로 지도 화면을 열어 콘솔 오류가 없는지, 지도 만들기 · 이동 시간 · 표 · 내보내기가 도는지 본다.

AGENTS.md 의 화면 파일 줄(`atlas.js` 를 부르는 곳)과 새 파일 줄.
