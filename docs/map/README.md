# 지도 작업 문서

Canon 지도 기능(장소 자리, 마을 · 도시 · 현대 동네 생성기, 실제 지도, 이동 시간 검사)의 설계 자산이다.
동작 설명은 [DESIGN.md](../../DESIGN.md)의 지도 절에 있다. 이 폴더는 그 위에서 일을 나누고 이어 가는 데 쓴다.

| 문서 | 내용 | 언제 읽나 |
|---|---|---|
| [modules.md](modules.md) | 지금 모듈 구조, 의존, 문제, 목표 구조, 옮기는 단계 | 지도 코드를 고치기 전 |
| [layout.md](layout.md) | 지도 데이터(레이아웃) 형식 명세: 키마다 만드는 곳 · 쓰는 곳 | 생성기 · 가져오기 · 그리기를 더하거나 바꿀 때 |
| [plan.md](plan.md) | 단기 일감 차례와 장기 후보 | 다음 일을 고를 때 |
| [specs/](specs/) | 일감마다 작업 명세서. 틀은 [specs/TEMPLATE.md](specs/TEMPLATE.md) | 일감을 시작할 때 |

## 정한 규칙

사용자와 정한 것이다. 바꾸려면 사용자와 다시 정한다.

| 날짜 | 규칙 |
|---|---|
| 2026-10-28 | 실제 지도(OpenStreetMap)에는 이름 · 번지를 지어 넣지 않는다. 가상 지도(마을 · 도시 · 현대 동네 생성기)는 짓는다. |
| 2026-10-28 | OSM 데이터는 작가가 파일로 올린다. Canon 이 공개 Overpass 서버에서 직접 받지 않는다. 직접 받기는 따로 운영하는 서버가 생긴 뒤에 다시 본다. |
| 2026-10-28 | OSM 지도의 화면 그림과 내보낸 그림에는 '© OpenStreetMap 기여자' 출처를 함께 그린다(ODbL 조건). |
| 2026-10-28 | 장소 자리 제안은 이름이 똑같을 때만 한다(띄어쓰기 무시). 일부만 같은 이름은 맞추지 않는다. 후보가 하나뿐이고 아직 놓지 않은 장소만 미리 고른다. |
| 2026-10-28 | 지도 정보를 프롬프트에 넣을 때는 이번 화 플롯에 나온 장소만, 예산(`context.BUDGET`) 안에서, 화마다 바뀌는 블록 쪽에 넣는다. |
| 2026-10-28 | 단기 차례: 장소 자리 제안 → 건물 한 줄 → 빈 블록 채우기 → 바다 → 지하철 → 이름표 다듬기. 같은 날 사용자가 지도 모듈 정리와 계획 문서를 먼저 하자고 했다([plan.md](plan.md) 의 차례). |
| 2026-10-28 | 지도 Python 코드는 `canon/maps/` 패키지로 옮긴다. 먼저 파일을 옮기지 않고 경계만 고치는 PR 을 하고(단계 1), 옮기기는 열린 지도 PR 이 없을 때 따로 한다(단계 2). `canon/atlas.py` 는 공개 면으로 남긴다([modules.md](modules.md)). |
| 2026-10-28 | `static/atlas.js` 는 지도 그림 · 화면 뼈대만 두고 지도 만들기 · 자리 찾기 · 이동 시간 · 표 · 내보내기를 화면 파일로 뗀다(단계 3). |
| 2026-10-28 | 지도 설계 자산은 이 폴더(`docs/map/`)에 둔다. DESIGN.md 는 동작 설명을 맡고 이 폴더를 가리킨다. |
| 2026-10-28 | OSM 빈 블록 채우기는 기본으로 하지 않는다. 작가가 지도 데이터 칸의 버튼으로 미리 보고 적용한다. 지은 건물은 화면에서 흐린 색과 점선 테두리로 그리고, 건물 메뉴에 '지은 건물(OpenStreetMap 에 없음)'이라고 보인다. 이름 · 주소 · 입점은 짓지 않고 쓰임 · 층수 · 사람 수만 둔다. |
| 2026-10-28 | 빈 블록을 채운 OSM 지도의 출처 글은 '© OpenStreetMap 기여자 · 빈 블록 건물은 Canon 이 지음'이다. 큰길 모퉁이 조각 블록(둘레 절반 이상이 큰길 가까이)은 채우지 않는다. |
| 2026-10-29 | OSM 바다는 해안선 방향(땅이 왼쪽, 바다가 오른쪽)을 믿고 닫는다. 방향이 어긋나 닫을 수 없으면 바다를 그리지 않고 지도 데이터 칸에 알림을 보인다. 섬 블록은 빈 블록 채우기가 채우지 않는다. |
| 2026-10-29 | 같은 이름의 길 이름표는 화면 폭의 1/4 안에 하나만 그린다. 확대하면 더 자주 보인다. |
