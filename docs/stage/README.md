# 장면 연출 작업 문서

Canon 장면 연출 기능의 설계 자산이다. 장면 연출은 방 하나 안에서 인물이 어디에 서고, 어떤 자세로, 누구의 어디를 어떻게 만지는지를 박자마다 적고 그림으로 재생하는 사이드바 도구다.
기능이 들어가면 동작 설명은 [DESIGN.md](../../DESIGN.md) 에 쓰고 이 폴더를 가리킨다. 이 폴더는 일을 나누고 이어 가는 데 쓴다.

| 문서 | 내용 | 언제 읽나 |
|---|---|---|
| [model.md](model.md) | 데이터 형식, 고정 어휘(부위 · 자세 · 향함 · 접촉 동작), 위치 계산, 검수 규칙 | 스키마 · 규칙 · 화면을 고치기 전 |
| [plan.md](plan.md) | 일감 차례와 2차 후보 | 다음 일을 고를 때 |
| [specs/](specs/) | 일감마다 작업 명세서. 틀은 지도 문서의 [TEMPLATE.md](../map/specs/TEMPLATE.md) | 일감을 시작할 때 |
| [mockup.html](mockup.html) | 화면 시안 (정적 HTML, 데이터는 가짜) | 화면을 만들기 전 |

## 정한 규칙

2026-10-29 에 사용자와 정한 것이다. 바꾸려면 사용자와 다시 정한다.

| 날짜 | 규칙 |
|---|---|
| 2026-10-29 | 1차는 사이드바 도구 화면 '장면 연출'만 만든다. 대화로 다듬기 패널(`chat.js`)은 데이터 모양이 굳은 뒤 2차로 붙인다. |
| 2026-10-29 | 목적은 쓰기 전 연출과 쓴 뒤 동선 검수다. 같은 데이터를 쓰기 프롬프트 재료로 다시 쓴다. 삽화 포즈 연결은 2차다. |
| 2026-10-29 | 공간은 방 · 실내 하나다. 마을 규모 이동은 지도(`atlas`, `travel`)가 맡는다. |
| 2026-10-29 | 그림은 2D SVG 다: 위에서 본 평면도, 막대 인형 자세 카드, 몸 부위 도식의 접촉 선. 3D 와 관절 편집은 하지 않는다. |
| 2026-10-29 | 데이터는 AI 초안 → 작가 고침 → 적용으로 만든다. 작가가 처음부터 짤 수도 있다. AI 초안은 장면 통째로 비교한 뒤 적용하고 적용 취소를 둔다. 박자 일부만 적용하지 않는다(박자는 앞 박자에서 바뀐 것만 적으므로 일부만 고르면 앞뒤가 깨진다). |
| 2026-10-29 | 가구는 좌표를 가진 기준점이다. 인물 위치는 '기준점 + 관계 말'로 저장하고 그림 좌표는 코드가 계산한다. AI 는 좌표를 읽거나 쓰지 않는다. DESIGN.md 검수 절의 '화마다 좌표나 배치도를 만들지 않는다'(모델이 좌표 추론에 약하다)와 맞춘 결정이다. |
| 2026-10-29 | 장면은 플롯 사건(`EpisodePlot.events`) 하나에 하나 붙는다. 사건은 번호와 사건 글 사본으로 찾는다. 한 사건에 장면이 둘 필요하면 사건을 나눈다. |
| 2026-10-29 | 장면은 박자 목록이다. 박자마다 바뀐 인물 · 칸만 적고 본문 문장 인용으로 본문과 잇는다. 화면은 슬라이더로 재생하고 박자 사이 이동을 보간 애니메이션으로 보인다. |
| 2026-10-29 | 부위 · 자세 · 향함 · 접촉 동작은 고정 목록이다. 목록 밖은 자유 메모로 적는다. |
| 2026-10-29 | 방은 틀에서 골라 끌어서 고친다. 방은 지도 장소에 묶어 여러 장면이 다시 쓴다. 장소가 없으면 장면 전용 방을 두고 나중에 장소에 묶는다. |
| 2026-10-29 | 성인 인물 사이 접촉은 성적 접촉까지 제한 없이 작가 전용 데이터로 다룬다. 미성년 인물(`cast.is_minor_age`)이 낀 성적 부위 · 성적 동작 접촉은 화면 입력, AI 초안 · 추출, 프롬프트 어디에서도 만들지 않는다. |
| 2026-10-29 | 쓰기 프롬프트에는 연출을 짠 사건만 박자 요약 글로 넣는다. 화마다 바뀌는 쪽, 예산 `context.BUDGET["stage"]` 안에서 넣고 뺀 수를 적는다. 장면마다 끌 수 있다. 전연령 작품(`Meta.adult` 거짓)은 성적 접촉 박자를 프롬프트에서 빼고 뺀 수를 작가에게 보인다. |
| 2026-10-29 | 장면 끝 상태는 같은 화 다음 장면의 시작값으로만 잇는다. 화를 넘는 옷 · 상처 · 물건 변화는 상태 변경안의 `CharacterState.attire` 가 맡고, 장면 연출은 `attire` 를 읽기만 한다. |
| 2026-10-29 | 1차 검수 규칙: 손(한 손 두 곳), 이동 자세(서지 않고 자리를 옮김), 거리(먼 사람과 접촉), 향함(등 뒤에서 몸 앞쪽 접촉), 물건(쥔 물건을 놓지 않고 다른 손으로 다시 쥠). 옷 겹 규칙은 2차다. |
| 2026-10-29 | 규칙 검수 결과는 검수 세션 지적 목록(`Episode.findings`)에 '동선' 지적으로 합치고 출처를 '규칙'으로 표시한다. 장면 연출 화면에도 그 박자에 표시한다. |
| 2026-10-29 | 본문에서 연출을 뽑는 AI 호출(`check` 단계)은 화면 버튼으로 돌린다. 설정 '검수 때 함께 뽑기'는 기본으로 끈다. 플롯에서 연출 초안을 만드는 호출은 `plan` 단계다. |
| 2026-10-29 | 연구 화면의 장면 상태표 검수(`check_scene`, `BodyState`)는 새 스키마로 옮긴다. 같은 일을 하는 스키마를 둘 두지 않는다. |
| 2026-10-29 | 장면 데이터는 상태가 아니라 작가 자료다. 스냅샷 · 반영 취소 대상이 아니고, 갈래는 `project.json` 을 복사하므로 함께 따라간다. 장면은 자동으로 지우지 않는다. |
| 2026-10-29 | 화면 이름은 '장면 연출', 주소는 `stage/<화>/<사건 번호>` 다. |
