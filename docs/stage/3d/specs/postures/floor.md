# 02-06. 자세 모듈: 바닥에 앉기 (`floor`)

상태: 명세 · 묶음: P2 · 공통: [../02-posture.md](../02-posture.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

바닥이나 침대 위에 책상다리로 앉는다.

## 정할 것

1. 다리를 뻗고 앉기를 따로 둘까 — 추천: 두지 않는다. 자세 목록은 고정(README 정한 규칙)이고 다른 모양은 메모로 적는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/postures/floor.py` (새) | `POSTURE = PostureSpec(id="floor", ...)` |
| `tests/test_stage3d_posture_floor.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

| 칸 | 값 |
|---|---|
| `id` | `floor` (`stage.POSTURES["floor"]`: 바닥에 앉기) |
| `angles` 첫 값 (시안) | pelvis_h 0.10, 허리 12, 어깨 25, 팔꿈치 40, 엉덩 82, 무릎 120, 다리 벌림 25 |
| `surface` | `floor`, `lie`(침대 위), `top` |
| `reach` | 숙임 35° · 비틀기 45° |
| 특수 배치 | 없음 |

## 시안 검토

시안 첫판은 두 무릎이 모여 쪼그린 모양이었다. 다리를 25° 벌려 책상다리로 고쳤다(`leg_abduct`).

## 시험

- 골반이 면 +0.10, 무릎이 면 위 0.25m 안, 발이 면 아래로 내려가지 않는다.
- 두 정강이가 서로 3cm 넘게 파고들지 않는다.
- 계약 시험(`tests/test_stage3d_contract.py`)이 이 자세에서 통과한다.
- 앞 · 옆 · 위 사진 세 장을 PR 에 붙인다.
