# 02-10. 자세 모듈: 옆으로 눕기 (`side`)

상태: 구현 (2026-10-29, PR #171, 시험 `tests/test_stage3d_postures_p3.py`, 사진 세 장은 아직) · 묶음: P3 · 공통: [../02-posture.md](../02-posture.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

옆으로 눕는다. 몸 앞이 어느 쪽을 보는지가 접촉(등 뒤에서 안기 등)에 중요하다.

## 정할 것

1. 향함이 몸축과 나란해 옆을 고를 수 없을 때 — 추천: 오른쪽이 아래(roll +90).

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/postures/side.py` (새) | `POSTURE = PostureSpec(id="side", ...)` |
| `tests/test_stage3d_posture_side.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

| 칸 | 값 |
|---|---|
| `id` | `side` (`stage.POSTURES["side"]`: 옆으로 눕기) |
| `angles` 첫 값 (시안) | pelvis_h 0.20, roll 90(오른쪽이 아래), 허리 10, 어깨 60, 팔꿈치 70, 엉덩 35 / 45, 무릎 45 / 60 |
| `surface` | `lie`, `floor` |
| `reach` | 숙임 0° · 비틀기 0°(팔만) |
| 특수 배치 | `place_hook`: 몸축은 '눕기'와 같다. 몸 앞이 향함 쪽을 보도록 아래쪽 옆(roll 의 부호)을 고른다. |

## 시안 검토

시안에서 그대로 읽혔다.

## 시험

- 향함이 몸축 왼쪽이면 roll −90, 오른쪽이면 +90.
- 모든 관절이 눕는 면 +0~0.45.
- 뒤에서 안는 사람(같은 침대, 같은 쪽 향함)의 가슴과 이 사람 등 사이가 0.15m 안에 놓일 수 있다(시험 장면).
- 계약 시험(`tests/test_stage3d_contract.py`)이 이 자세에서 통과한다.
- 앞 · 옆 · 위 사진 세 장을 PR 에 붙인다.
