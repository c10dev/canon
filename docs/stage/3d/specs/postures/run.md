# 02-03. 자세 모듈: 뛰기 (`run`)

상태: 명세 · 묶음: P1 · 공통: [../02-posture.md](../02-posture.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

뛰는 한 순간. 손 닿기 여유가 가장 작다(뛰면서 붙잡기).

## 정할 것

1. 두 발이 다 떠도 될까 — 추천: 낮은 발이 바닥에서 0.05m 안이면 된다(공중 자세는 받침 판정에서 빼지 않는다).

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/postures/run.py` (새) | `POSTURE = PostureSpec(id="run", ...)` |
| `tests/test_stage3d_posture_run.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

| 칸 | 값 |
|---|---|
| `id` | `run` (`stage.POSTURES["run"]`: 뛰기) |
| `angles` 첫 값 (시안) | pelvis_h 0.86, 허리 16, 어깨 −40 / 50, 팔꿈치 85, 엉덩 62 / −22, 무릎 70 / 40 |
| `surface` | `floor` |
| `reach` | 숙임 15° · 비틀기 20° |
| 특수 배치 | 없음 |

## 시안 검토

시안에서 몸통이 앞으로 기울고 뒷다리가 차올라 읽혔다. 고칠 것 없음.

## 시험

- 낮은 발이 바닥 0.05m 안.
- 자기 몸 겹침 3cm 안(팔꿈치 85° 아래팔이 몸통에 닿지 않는다).
- 계약 시험(`tests/test_stage3d_contract.py`)이 이 자세에서 통과한다.
- 앞 · 옆 · 위 사진 세 장을 PR 에 붙인다.
