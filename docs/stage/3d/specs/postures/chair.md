# 02-05. 자세 모듈: 의자에 앉기 (`chair`)

상태: 구현 (2026-10-29, 시안에서 고친 각도와 이유는 `canon/stage3d/postures/chair.py` 머리 주석, 사진 확인 전) · 묶음: P2 · 공통: [../02-posture.md](../02-posture.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

앉을 수 있는 기준점(`sit` 참)에 앉는다. 침대 가장자리 · 소파 · 차 좌석도 이 자세다.

## 정할 것

1. 앉는 쪽 — 추천: 몸은 향함을 따른다. 기준점 앞쪽(`rot`)과 90° 넘게 다르면 등받이에 등이 닿지 않으므로 `shift` 를 0 으로 둔다(침대 · 소파 옆으로 걸터앉기).
2. 책상 · 탁자(`sit` 거짓)에 앉기 — 추천: `no_support` 로 짚는다. 작가가 기준점의 '앉기'를 켜면 통과한다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/postures/chair.py` (새) | `POSTURE = PostureSpec(id="chair", ...)` |
| `tests/test_stage3d_posture_chair.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

| 칸 | 값 |
|---|---|
| `id` | `chair` (`stage.POSTURES["chair"]`: 의자에 앉기) |
| `angles` 첫 값 (시안) | pelvis_h 0.08(앉는 면 위), 허리 6, 어깨 22, 팔꿈치 60, 엉덩 90, 무릎 90, 옮김 −0.13 |
| `surface` | `seat` |
| `reach` | 숙임 30° · 비틀기 40° |
| 특수 배치 | `feet_to_floor`: 앉는 면이 0.45m 와 다르면 무릎 각을 고쳐 발목이 바닥에 닿게 한다(침대 0.5, 소파 0.42, 차 좌석 0.3). 닿지 않으면(높은 의자) 발을 늘어뜨린다. |

## 시안 검토

시안 첫판은 골반이 기준점 가운데에 있어 넓적다리가 의자 앞으로 떠 있었다. 엉덩이를 등받이 쪽으로 0.13m 옮겼다(`shift`).

## 시험

- 앉는 면 0.42 · 0.45 · 0.5 에서 골반이 면 +0.08, 발목이 바닥 ±0.03.
- 넓적다리가 앉는 면 상자를 3cm 넘게 파고들지 않는다.
- 등받이 앞쪽(`rot` 0 · 90 · 180 · 270)에서 등이 등받이 쪽.
- 계약 시험(`tests/test_stage3d_contract.py`)이 이 자세에서 통과한다.
- 앞 · 옆 · 위 사진 세 장을 PR 에 붙인다.
