상태: 완료 (2026-10-29, 브랜치 claude/s3d-p1-4a5e6d, 시험 tests/test_stage3d_postures_p1.py, 사진은 아직 없음) · 묶음: P1 · 공통: [../02-posture.md](../02-posture.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

박자 하나의 걷는 모습. 판정에는 '선 자세로 옮김'의 증거이고 손 닿기 여유가 서기보다 작다.

## 정할 것

1. 보폭 모양을 박자마다 바꿀까 — 추천: 한 모양으로 둔다. 박자 끝 상태만 보므로 걸음 위상은 뜻이 없다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/postures/walk.py` (새) | `POSTURE = PostureSpec(id="walk", ...)` |
| `tests/test_stage3d_posture_walk.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

| 칸 | 값 |
|---|---|
| `id` | `walk` (`stage.POSTURES["walk"]`: 걷기) |
| `angles` 첫 값 (시안) | pelvis_h 0.90, 허리 4, 어깨 25 / −20, 팔꿈치 20, 엉덩 −18 / 24, 무릎 28 / 6 |
| `surface` | `floor` |
| `reach` | 숙임 20° · 비틀기 30° |
| 특수 배치 | 없음 |

## 시안 검토

시안에서 팔 · 다리가 엇갈려(왼팔 앞 · 오른다리 앞) 자연스러웠다. 고칠 것 없음.

## 시험

- 낮은 발이 바닥 ±0.02, 다른 발은 0.10m 안.
- 자기 몸 겹침 3cm 안.
- 골반 높이가 서기보다 0.02 낮다.
- 계약 시험(`tests/test_stage3d_contract.py`)이 이 자세에서 통과한다.
- 앞 · 옆 · 위 사진 세 장을 PR 에 붙인다.
