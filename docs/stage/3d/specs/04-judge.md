# 04. 3D 판정

상태: 완료 (`canon/stage3d/judge.py`, 시험 `tests/test_stage3d_judge.py`, 브랜치 `claude/s3d-judge-152b88`) · 지도: [../README.md](../README.md) 의 04 · 먼저: [01-body.md](01-body.md) · 이어서: [07-wire.md](07-wire.md)

## 목표

평면 판정(`stage.judge`)이 통과시킨 장면에서 높이와 몸 부피 때문에 말이 안 되는 박자를 찾는다. 결과는 `stage.Violation` 목록이라 2D 지적과 같은 길로 검수 세션에 들어간다(연결은 07).

## 정할 것

[../README.md](../README.md) 의 정할 것 5(문턱), 6(2D 와 겹치면 2D 만), 7(박자 끝 상태만), 8(`place` 좌표 그대로)을 따른다. 이 모듈만의 것:

1. 이어지는 접촉도 볼까 — 추천: `reach3d` 는 접촉이 시작된 박자와, 접촉이 이어지는 동안 두 사람 중 하나의 자리 · 자세가 바뀐 박자에 본다(일어서며 잡은 손목을 놓지 않는 경우). 2D `reach` 는 시작 박자만 보지만, 높이는 자세가 바뀔 때 어긋나기 쉽다.
2. 한 박자에 같은 겹침이 여러 마디에서 나오면 — 추천: 인물 쌍(또는 인물 · 기준점)마다 하나로 묶고 가장 깊은 마디를 글에 적는다.

## 계약 (입력 · 출력)

- 입력: 장면, 방, 작품(이름 · 미성년), 선택으로 미리 구한 `frames`(없으면 `stage3d.frames` 를 부른다), 선택으로 2D 판정 결과 `flat`(없으면 `stage.judge` 를 부른다. 겹침 빼기에 쓴다).
- 출력: `stage.Violation(beat, cause, who, rule, text, contact)` 목록. `contact` 는 일감 1-1(PR #163)이 더한 칸이다. 박자 순, 같은 박자는 규칙 이름 순.
- 자세 · 장소 모듈이 없는 인물 · 기준점은 판정하지 않는다(헛지적 막기). 등록부가 덜 찼으면 07 이 이 함수를 부르지 않는다(README 정할 것 10).

## 규칙

`RULES3D` (이름은 2D `RULES` 와 겹치지 않는다):

| 규칙 id | 화면 이름 | 판정 | 문턱 (제안값) |
|---|---|---|---|
| `reach3d` | 높이 | 손 접촉: 그 자세의 `reach`(숙임 · 비틀기) 안에서 손끝과 부위 점 사이 틈. 손 아닌 부위 접촉(`by` 가 부위 id)은 두 부위 점 사이 | 손 0.05m, 부위 0.08m. 2D `reach` 가 같은 접촉을 짚었으면 내지 않는다 |
| `body_overlap` | 몸 겹침 | 두 사람의 몸 캡슐이 파고듦 | 0.03m. 접촉 · 받침 중인 두 사람은 접촉 부위 segment 와 손 · 팔 segment 를 뺀다. 매단 사람(`attach`)과 받치는 사람 사이는 0.08m |
| `furniture_overlap` | 가구 | 몸 캡슐이 가구 `solid` 상자 · 방 벽을 파고듦 | 0.05m. 그 사람이 앉거나 누운 기준점(자리 `on` · `in`)의 앉는 판 · 눕는 판, 기대는 기준점(`against`)은 뺀다 |
| `no_support` | 받침 | 자세 모듈 `surface` 를 못 채움: 앉기 자세인데 앉는 면이 없음, 눕기인데 몸이 눕는 면 밖으로 0.15m 넘게 나감('누울 자리가 짧아요'), 기대 서기인데 등 뒤 면이 없음, 안기거나 업히기인데 받치는 사람이 없음 | 위 |
| `headroom` | 천장 | 머리 꼭대기가 장소 모듈 `ceiling` 보다 높음 | 선 자세 0.0m, 앉은 자세 0.05m |

- `cause`: 그 상태를 만든 박자(2D 와 같은 뜻). `reach3d` 는 두 사람의 자리 · 자세가 마지막으로 바뀐 박자 중 늦은 것. 겹침은 두 사람(또는 사람)의 자리 · 자세가 마지막으로 바뀐 박자.
- 글은 해요체. 예: "도윤 → 하린 뺨: 하린이 바닥에 누워 있어 선 채로는 손이 0.4m 모자라요. 무릎을 꿇거나 앉는 박자가 필요해요." "하린과 도윤이 0.1m 겹쳐요." "하린 다리가 책상에 0.2m 파고들어요." "차 안이라 서면 머리가 천장에 닿아요."
- 미성년 막기는 판정 대상이 아니다(막은 접촉은 `clean_scene` 이 이미 뺐다).
- 한 장면(인물 4명, 박자 20개) 판정이 0.2초 안(제안값).

## 시험

시험용 가짜 등록부(서기 · 의자에 앉기 · 눕기 세 자세, 상자 하나 방)를 `monkeypatch` 로 넣어 자세 · 장소 모듈 없이 돈다. 실제 자세로 문턱을 고치는 일은 07 이다.

- `reach3d`: 선 사람 → 바닥에 누운 사람 뺨(평면 0.5m)이 짚힌다. 쪼그린 사람이면 통과(가짜 등록부에 쪼그리기가 없으면 '서기 + 숙임 90°' 가짜 자세로 대신한다). 2D `reach` 가 짚은 접촉은 다시 짚지 않는다.
- `reach3d` 이어짐: 앉아서 손목을 잡은 채 상대가 일어서는 박자에 짚힌다(정할 것 1).
- `body_overlap`: 같은 자리 `@인물 on` 두 사람이 짚힌다. 손을 잡은 두 사람(0.55m)은 통과.
- `furniture_overlap`: 자리를 책상 `on` 에 둔 '서기'는 통과(윗면), 책상 `in` 의 '서기'는 짚힌다. 의자 `on` 의 '의자에 앉기'는 통과.
- `no_support`: 자리를 방 가운데에 둔 '의자에 앉기'가 짚힌다.
- `headroom`: 천장 1.15 가짜 방의 '서기'가 짚힌다.
- 같은 입력이면 같은 결과, 박자 · 규칙 순서.
- 전체 시험.

## 야외 틀 (2026-10-29)

- `RoomSpec.open` 이 참이면(차 옆 · 야외 빈터) 방 테두리 파고듦(벽)과 `headroom` 을 보지 않는다. 다가서기도 테두리에서 멈추지 않는다.
- 두 사람의 골반을 잇는 평면 선분이 막(`barrier`) 상자를 지나면 몸 겹침을 보지 않는다(차체 · 창 면으로 갈림).
- 손 접촉의 어깨 → 목표 선분이 막 상자를 지나면 `reach3d`('차체에 막혀 손이 닿지 않아요'). 목표가 손 · 손가락 · 손목 · 아래팔이면 받는 사람의 같은 쪽 어깨까지 본다(`MEET`).
- 자세한 것은 [rooms/car_side.md](rooms/car_side.md).
