# 03-05. 장소 모듈: 차 안 (`car`)

상태: 명세 · 묶음: R · 공통: [../03-room.md](../03-room.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

`stage.ROOMS["car"]`(차 안, 1.8 × 3.0m)의 기준점에 높이 · 모양을 더하고 천장 높이를 정한다.

## 정할 것

1. 앉은 머리 · 천장 허용 — 추천: 앉은 자세는 천장 0.05m 넘게 파고들 때만 짚는다(작은 차에서 머리가 닿는 것은 흔하다).
2. 앞좌석 사이(콘솔) — 추천: 두지 않는다. 앞좌석 사이 건너기는 2D 이동 자세 판정으로 충분하다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage3d/rooms/car.py` (새) | `ROOM = RoomSpec(template="car", ceiling=1.15, anchors={...})` |
| `tests/test_stage3d_room_car.py` (새) | 아래 '시험' |

## 계약 (입력 · 출력)

천장: **1.15m**

| 기준점 이름 | 종류 | 모양 (높이 m) | 앉는 면 · 눕는 면 | 근거 (흔한 치수 어림) |
|---|---|---|---|---|
| 운전석 · 조수석 | `seat` | **덮어씀**: 앉는 판 0~0.30, 등받이(v 0~0.15) 0~0.95 | seat 0.30 | 승용차 앉는 면(차 바닥 기준) 약 0.25~0.30, 실내 높이 약 1.15~1.25 |
| 뒷좌석 | `seat` | **덮어씀**: 앉는 판 0~0.30, 등받이 0~0.85 | seat 0.30 · lie 0.30 |  |
| 앞유리 | `window` | 유리 0.6~1.1 (solid 아님) | — |  |

'종류 기본값'이라 적은 줄은 `anchors` 에 넣지 않는다. '덮어씀'만 넣는다.

## 특이점

천장이 1.15m 라 '서기' · '걷기'는 `headroom` 으로 짚인다. 앉은 키(약 0.9m) + 앉는 면 0.30 = 1.2m 라 앉은 사람 머리가 천장에 닿을 수 있다. 차 바닥이 z 0 이다.

## 시험

- 계약 시험과 빈자리 시험([../03-room.md](../03-room.md))이 이 틀에서 통과한다.
- 운전석 `on` 에 '서기'를 두면 `headroom` 이 한 번.
- 운전석에 '의자에 앉기'는 지적이 없다.
- 뒷좌석 `on` 에 '눕기'(1.5m 좌석)는 다리가 좌석 밖으로 나가 `no_support`('누울 자리가 짧아요')가 한 번 나온다([../04-judge.md](../04-judge.md)).
- 위에서 · 비스듬히 사진 두 장을 PR 에 붙인다.
