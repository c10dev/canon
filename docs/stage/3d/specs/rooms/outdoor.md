# 03-09. 장소 모듈: 야외 빈터 (`outdoor`, 야외)

상태: 완료 (`canon/stage3d/rooms/outdoor.py`, 시험 `tests/test_stage3d_outside.py` · `tests/test_stage3d_rooms.py`, 장면 `tests/stage3d_scenes/*outdoor*`) · 공통: [../03-room.md](../03-room.md) · 먼저: [../01-body.md](../01-body.md)

## 목표

벽 · 천장 없는 넓은 땅(12 × 10m)에서 벌어지는 장면. 기준점은 길 · 나무 · 바위 같은 표지다.

## 정한 것

1. **벽 · 천장** — 없다(`RoomSpec.open`). 판정은 방 테두리(벽) 파고듦과 `headroom` 을 보지 않고, 다가서기(`_stepped`)도 테두리에서 멈추지 않는다. 방 테두리는 그린 땅의 끝이다. `ceiling` 4.0 은 그림 높이고, 그림은 벽 대신 낮은 테두리만 그린다.
2. **새 종류** — `landmark`(표지: 기본 0~1.0m 덩어리), `ground`(길 · 땅: 걷는 면, 막지 않음). 둘은 `stage.ANCHOR_KINDS` 와 화면 방 고치기 종류 목록에도 있다.

## 계약 (입력 · 출력)

| 기준점 | 종류 | 자리 (x, y, w, h, rot) | 모양 (높이 m) | 앉는 면 | 근거 (어림) |
|---|---|---|---|---|---|
| 길 | `ground` | 0, 4.2, 12, 1.6, 0 | 종류 기본값 (막지 않음 0~0.02) | — | 시골길 폭 약 1.5m |
| 큰 나무 | `landmark` | 2.0, 1.0, 1.2, 1.2, 0 | 줄기 0~2.4 (가운데 0.24m), 가지 2.4~4.0 (막지 않음) | — |  |
| 바위 | `landmark` | 8.5, 1.5, 1.0, 0.8, 0 (앉기) | 0~0.5 | 0.5 | 걸터앉는 바위 |
| 표지판 | `landmark` | 9.5, 7.0, 0.4, 0.2, 180 | 기둥 0~1.4, 판 1.4~2.0 | — |  |
| 모닥불 | `landmark` | 5.5, 7.5, 0.8, 0.8, 0 | 0~0.3 | — | 돌로 두른 불 자리 |

## 시험

- 계약 · 빈자리 시험([../03-room.md](../03-room.md))이 이 틀에서 통과한다.
- `ok_outdoor_camp`: 바위에 앉은 사람과 나무 · 길 · 표지판을 오가는 사람, 어깨를 짚고 모닥불 앞에 쪼그려 앉는다. 2D · 3D 지적 0.
- `bad_outdoor_tree`: 큰 나무 줄기 안으로 걸어 들어간다 → `furniture_overlap`.
- 같은 장면에 천장 1.5m 를 주면 닫힌 방은 천장 · 벽을 짚고, 야외(`open`)는 짚지 않는다.

## 확인하지 못할 것

표지 배치가 그 작품의 장소에 맞는지는 사용자 판단이다. 작가가 방 고치기에서 표지를 더하거나 옮긴다.
