# 07. 연결 (3D 판정을 검수에)

상태: 끝 (2026-10-29, 브랜치 `claude/s3d-wire-77f7ca`, 시험 `tests/test_stage3d_wire.py` · `tests/stage3d_scenes/`) · 지도: [../README.md](../README.md) 의 07 · 먼저: [04-judge.md](04-judge.md), 자세 12 · 장소 7, 장면 일감 07(계획 · 본문 장면) · 1-1(PR #163)

## 목표

3D 판정 결과를 2D 규칙 지적과 같은 길로 보낸다: 장면 연출 화면의 박자 표시, 검수 세션의 '동선' 지적(출처 '규칙', 심각도 '사소'). 실제 자세 · 장소로 판정 문턱을 시험 장면으로 고친다.

## 정할 것

[../README.md](../README.md) 의 정할 것 6(2D 우선), 10(등록부가 다 찼을 때만)을 따른다. 이 모듈만의 것:

1. 3D 판정을 어느 장면에 (정함 2026-10-29, 추천안대로) — 추천: 장면 일감 07 의 두 역할 모두. 계획 장면(쓰기 전)은 화면 표시만, 본문 장면(쓴 뒤)은 검수 지적까지. 2D 규칙과 같은 길이다.
2. 비용 (정함 2026-10-29, 추천안대로) — 추천: 따로 재지 않는다. LLM 호출이 없고 한 장면 0.2초 안(04 의 제안값)이다.

## 계약 (입력 · 출력)

- `stage.check(...)` 의 `violations` 에 3D 규칙이 섞인다. 모양은 같다(`stage.Violation`). 화면은 `vocab()["rules"]` 로 이름을 안다.
- 등록부가 덜 차면 3D 지적은 없다. 화면은 05 의 `missing` 으로 '3D 판정 준비 중: 자세 N개 · 틀 M개 남음' 을 보일 수 있다.

## 규칙

- 시험 장면 10개 이상을 만든다. 절반은 말이 되는 장면(지적 0 이어야), 절반은 일부러 어긋난 장면(규칙마다 하나 이상). 말이 되는 장면에서 지적이 나오면 문턱을 고치거나 자세 · 장소 모듈에 이슈를 남긴다.

## 확인하지 못할 것

실제 작품 장면의 헛지적률. 사용자가 실제 작품 몇 화를 검수하고 3D 지적을 '그대로 둠'으로 닫은 수를 보아 문턱을 다시 정한다.

## 구현 (2026-10-29)

- 연결: `stage.judge_all(scene, room, p)` = `stage.judge` + `stage3d.judge.judge_if_ready(…, flat=)`. `stage.check`(화면 · 계획 · 본문 장면), `stage.to_issues`(검수 지적, 본문 장면), 웹의 AI 장면 비교(`_stage_view` proposals)가 이것을 부른다. 검수 지적 글은 `규칙 이름: 설명` 이고 이름표는 `stage.rule_names()`(2D `RULES` + `RULES3D`). `vocab()` 이 `rules` · `rules3d` 를 내리고 장면 연출 화면은 3D 규칙 앞에 '3D · 높이' 칩을 단다(`stgRuleTag`). 3D 보기 엔드포인트의 `violations3d` 는 같은 지적이다(렌더러가 빨간 표시에 쓴다). `stage3d.ready()` 는 `complete()` 와 같다. 검수 세션 연결부(`pipeline.apply_check` · `recheck_finding`, `research._stage_run`)는 `episode_issues` 를 부르므로 고칠 것이 없었다.
- 계약 빈틈 (모듈 PR #168~#173 이 적은 것):

| 빈틈 | 고침 |

| 자세가 배치 뒤 각도를 못 바꿈 (옆 눕기 좌우) | `Placement.angles`. `side` 가 향함이 몸축 오른쪽이면 roll −90 · 좌우 짝을 바꾼 각도(`side.LEFT_DOWN`)를 낸다 |
| side 명세의 roll 부호 | 명세 시험 줄을 01 좌표에 맞게 고쳤다(왼쪽이면 +90) |

| 뼈대에 엉덩이 돌림 · 발목이 없음 | `Angles.hip_rot` · `ankle` (사용자 결정). 바닥에 앉기는 양반다리, 쪼그려 앉기는 뒤꿈치를 대고, 침대 걸터앉기는 발이 바닥에 닿는다 |

- 시험 장면 19개(`tests/stage3d_scenes/`, 말이 되는 11 · 어긋난 8, 규칙 다섯 모두). 처음 실제 자세로 돌리자 말이 되는 장면 10개 중 9개에서 헛지적이 났다. 원인과 고침:
  - 향함을 모르면 +y 를 봐서 벽 · 가구로 몸이 들어가거나 옆 사람에게 손을 뒤로 뻗었다 → `default_facing`.
  - 같은 침대 · 소파 위 두 사람은 평면 자리가 기준점 가운데라 어디쯤 앉았는지 모른다(머리맡에 걸터앉아 머리를 쓰다듬기가 0.29m 모자람) → 두 사람이 같은 기준점 `on` · `in` 이면 `reach3d` 를 보지 않는다.
  - 팔은 작가가 정하지 않은 자세 표 값이라 책장 · 벽에 6~20cm 들어갔다 → `furniture_overlap` 은 팔 캡슐을 보지 않는다.
  - 걷기 보폭의 발이 소파에 5~7cm → 발 · 가구 문턱 `FOOT_DEPTH` 0.10m (실제 가구는 아래에 발이 들어갈 틈이 있다). 벽은 0.05 그대로.
  - 나란히 선 두 사람(0.5m)의 팔이 5cm 겹쳤다(`tests/test_smoke.py` 의 가짜 본문 장면) → `body_overlap` 도 팔을 늘 뺀다.
  - 누울 자리가 짧거나 받치는 사람이 없는 사람은 다리 · 팔이 벽에도 들어가 지적이 둘 났다 → `no_support` 가 난 사람은 그 박자 `furniture_overlap` 을 내지 않는다.
  - 옆자리 사람의 먼 어깨 · 먼 팔을 반대 손으로 잡는 장면 두 개는 3D 로 실제로 모자라(0.14~0.38m) 장면 쪽을 가까운 손 · 가까운 어깨로 고쳤다. 판정은 그대로 짚는다.
- 문턱 숫자(손 0.05, 부위 0.08, 몸 0.03, 매단 사람 0.08, 가구 · 벽 0.05, 눕는 면 0.15, 천장 0 · 0.05)는 그대로 두고 발 0.10 만 더했다.
- 2D 문턱: #167 의 2D 측정 세트는 아직 없다. 3D 몸으로 마주 본 두 사람 사이 거리를 늘려 쟀다: 선 두 사람 손 → 손 0.62m, 어깨 0.90m, 뺨 0.92m, 선 사람 → 앉은 사람 어깨 0.74m, 앉은 두 사람 손 1.1m, 쪼그린 사람 → 바닥에 앉은 머리 1.08m. 2D `REACH_HAND` 1.2 는 자세를 모르는 거친 거름으로 두고(낮추면 앉은 두 사람 1.1m 를 헛짚는다) 그 사이는 3D 가 잡는다. 2D 문턱은 바꾸지 않았다.
