## 2차 후보

정하지 않은 것이다. 시작하기 전에 사용자와 정한다.

| 후보 | 왜 | 먼저 필요한 것 |
|---|---|---|
| 옷 겹 규칙 | 벗지 않은 옷 아래 부위를 바로 만지는 어긋남을 잡는다 | `attire` 줄글을 옷 겹 목록과 부위로 잇기 |
| 대화로 다듬기 패널 | "하린이 뒤에서 어깨를 잡게"처럼 말로 고친다 | 1차 스키마가 굳은 뒤 `chat.js` 주제 |
| AI 방 배치 제안 | 장소 설명으로 방 틀과 기준점을 제안한다 | 대화 패널 |
| 삽화 태그 연결 | 박자 하나를 고르면 `IllustCharacter.action` 과 `position` 을 채운다 | `ACTS` 의 태그 이름 |
| 플레이 모드 연결 | 결정 장면에 자리 · 접촉을 보인다 | 플레이 모드 설계(DESIGN.md 10장) |
| shadowcast 엔진으로 판정 바꾸기 | 판정기를 외부 공개 패키지와 함께 쓴다 | shadowcast 엔진 패키지([01-model.md](specs/01-model.md) 의 정할 것 1) |
| 실내 여러 방 · 층 | 저택 · 학교 안 추격 | 방 사이 문 잇기, 지도의 '실내 평면도' 후보와 함께 |
| 규칙 `crowd` | 앉기 · 눕기 기준점 하나에 정원보다 많은 인물(의자 하나에 둘) | 기준점에 정원 칸 |
| 규칙 `side_flip` | 설명 없이 두 인물의 좌우가 뒤바뀜(영화 180도 규칙의 소설판) | 박자 사이 좌우 판정, 헛지적률 측정 |
| 규칙 `teleport` | 한 박자에 방 대각선 이상 옮기는데 걷기 · 뛰기가 아님 | 거리 문턱 시험 |
| 규칙 `contact_break` | 접촉 중인 두 인물이 끝내기 없이 멀어짐(`reach` 의 이어지는 판) | 없음 |
| 경로 · 가구 겹침 표시 | 보간 직선이 가구를 뚫고 지나가 어색하다(ActThread 의 겹침 경고). 1차는 표시만, 다음에 돌아가는 길 | 가구 사각형 · 선분 겹침 계산 |
| 관계 말 `near` · `between` | 거리만 가까움, 두 기준 사이 | `across` · `against` 를 써 본 뒤 |
| 인물별 허용 부위 | 친밀 장면 조율의 몸 지도(허용 · 조건부 · 금지)처럼 인물마다 경계를 적는다. 관계에 비해 과한 접촉 경고(Suvilehto 2015) | 작가 수요 확인 |
