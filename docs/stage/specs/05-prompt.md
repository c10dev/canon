# 05. 쓰기 프롬프트 블록

상태: 구현 (화면 스위치 · 뺀 박자 안내는 일감 02) · 계획: [plan.md](../plan.md) 의 5번 · 먼저: 1번

## 목표

작가가 연출을 짠 사건은 AI 가 본문을 쓸 때 그 자리 · 자세 · 접촉을 따른다.

## 정할 것

2026-10-29 사용자와 정했다(둘 다 추천안).

1. 예산 — `context.BUDGET["stage"] = 1_500`. 넘으면 사건 순서대로 넣고 남은 장면 수를 적는다. 첫 장면은 넘어도 넣는다.
2. 박자 요약의 모양 — 장면마다 "사건 N · 방 이름 · 기준점 목록" 한 줄, 그 아래 박자마다 "1. 하린: 문 앞 서기 → 침대 옆, 왼손으로 도윤 오른 손목 잡기". 인물 이름과 기준점 이름만 쓰고 좌표는 쓰지 않는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage.py` | `episode_lines(p, ep) -> (lines, dropped, filtered)`: `dropped` 는 미성년이라 뺀 접촉 수, 사건을 찾지 못한 장면도 뺌. `prompt` 가 참인 장면만, `blocked` 접촉은 늘 빼고, 전연령 작품이면 `sexual` 접촉도 뺌. `filtered` 는 수위로 뺀 박자 수 |
| `canon/prompts.py` | `stage_block`: 줄 데이터를 글로, 예산에 맞춰 뺀 수 적기. 쓰기 프롬프트의 화마다 바뀌는 쪽, 지도 블록(`mapprompt.spot_block`) 뒤에. 작업지시서(`episode_brief`)도 같은 함수 |
| `canon/context.py` | `BUDGET["stage"]` |
| `canon/static/stage.js` | 장면마다 '쓰기에 넣기' 스위치, 전연령 작품에서 뺀 박자 수 안내("전연령 작품이라 성적 접촉 박자 N개는 쓰기 프롬프트에서 뺐어요") |

## 시험

- 블록이 `static_context()` 뒤에 온다(캐시 순서).
- 예산을 넘으면 뺀 수가 적힌다.
- 전연령 작품에서 `sexual` 접촉이 빠지고, 성인 작품에서 들어간다. 미성년 인물이 낀 성적 접촉은 어느 작품에서도 들어가지 않는다.
- `brief` 출력에 같은 블록이 있다.
- 단편 경로도 같은 블록을 쓴다(장면이 없으면 빈 글).

## 확인하지 못할 것

실제 모델이 박자를 따라 쓰는지. 사용자가 할 단계: 연출을 짠 화 하나를 써 보고, '본문에서 뽑기' 결과가 짠 연출과 같은지 비교 보기로 본다.
