# 05. 쓰기 프롬프트 블록

상태: 설계 · 계획: [plan.md](../plan.md) 의 5번 · 먼저: 1번

## 목표

작가가 짠 계획 장면을 AI 가 본문을 쓸 때 어기지 않는다. 다만 본문이 동작 묘사로 쏠리지 않게 한다(2026-10-29 두 역할 결정: 장면 연출은 은연중에, 뒤에서 매끄러움을 잡는 도구).

## 두 층 (2026-10-29 결정, 구현 고침)

1. **지시**: 박자 설명(`StageBeat.note`)은 작가가 적은 그대로 넣는다. 작가 의도라서다.
2. **배경 제약**: 자리 · 자세 · 향함 · 접촉은 블록 머리에 이 규칙을 붙여 넣는다. "아래 배치는 장면의 배경 제약이다. 본문이 이 배치와 어긋나지 않게만 쓰고, 동작 · 자리를 하나하나 묘사하지 않는다. 장면에 필요한 것만 자연스럽게 드러낸다." 박자 줄도 동작 낱말을 늘어놓지 않게 짧게 쓴다.
- 계획 장면(`role = plan`, 일감 07)만 넣는다. 본문 장면은 넣지 않는다.

## 정할 것

1. 예산 — 추천: `context.BUDGET["stage"] = 1_500`. 넘으면 사건 순서대로 넣고 남은 장면 수를 적는다.
2. 박자 요약의 모양 — 추천: 장면마다 "사건 N · 방 이름 · 기준점 목록" 한 줄, 그 아래 박자마다 "1. 하린: 문 앞 서기 → 침대 옆, 왼손으로 도윤 오른 손목 잡기". 인물 이름과 기준점 이름만 쓰고 좌표는 쓰지 않는다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/stage.py` | `episode_lines(p, ep) -> (lines, dropped, filtered)`: `prompt` 가 참인 장면만, `blocked` 접촉은 늘 빼고, 전연령 작품이면 `sexual` 접촉도 뺌. `filtered` 는 수위로 뺀 박자 수 |
| `canon/prompts.py` | `stage_block`: 줄 데이터를 글로, 예산에 맞춰 뺀 수 적기. 쓰기 프롬프트의 화마다 바뀌는 쪽, 지도 블록(`mapprompt.spot_block`) 뒤에. 작업지시서(`episode_brief`)도 같은 함수 |
| `canon/context.py` | `BUDGET["stage"]` |
| `canon/static/stage.js` | 장면마다 '쓰기에 넣기' 스위치, 전연령 작품에서 뺀 박자 수 안내("전연령 작품이라 성적 접촉 박자 N개는 쓰기 프롬프트에서 뺐어요") |

## 시험

- 블록이 `static_context()` 뒤에 온다(캐시 순서).
- 예산을 넘으면 뺀 수가 적힌다.
- 전연령 작품에서 `sexual` 접촉이 빠지고, 성인 작품에서 들어간다. 미성년 인물이 낀 성적 접촉은 어느 작품에서도 들어가지 않는다.
- `brief` 출력에 같은 블록이 있다.
- 단편 경로도 같은 블록을 쓴다(장면이 없으면 빈 글).
