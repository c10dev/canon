# 03. AI 초안 · 추출, 연구 화면 옮기기

상태: 설계 · 계획: [plan.md](../plan.md) 의 3번 · 먼저: 1번

## 목표

작가가 버튼 하나로 플롯 사건에서 연출 초안을 받거나, 쓴 본문에서 연출을 뽑는다. 결과는 지금 장면과 나란히 비교한 뒤 통째로 적용하고, 적용 취소로 되돌린다.

## 정할 것

1. 한 장면에 넣는 본문 범위 — 추천: 사건과 장면을 본문에서 잇는 표시가 없으므로, 화 본문 전체를 넣고 "이 사건에 해당하는 부분만" 뽑게 한다. 박자는 40개까지(`SCENE_BEATS` 와 같은 값). 다른 안: 작가가 본문에서 범위를 골라 넣는다.
2. 연구 화면 검수 시험 — 추천: `scene` 방식을 `stage` 방식으로 바꾼다. 화 전체를 한 장면으로 뽑고 `stage.judge` 결과를 지적으로 낸다. 옛 `SceneCheck` · `BodyState` · `SceneBeat` 는 지운다.

## 바꿀 곳

| 파일 | 바꿀 것 |
|---|---|
| `canon/schema.py` | LLM 출력 `StageDraft`(이름 기반, dict 없음). `SceneCheck` · `SceneBeat` · `BodyState` 지우기 |
| `canon/prompts.py` | `stage_draft_prompt`(플롯 사건 · 방 기준점 이름 · 등장 인물 · 직전 장면 끝 상태 · 직전 화 `attire` · 어휘 목록), `stage_extract_prompt`(본문 + 같은 재료, 인용은 원문 그대로 한 문장). 바뀌지 않는 어휘 목록을 앞에, 화마다 바뀌는 재료를 뒤에. 미성년 인물 목록과 "이 인물이 낀 성적 접촉은 적지 않는다" 규칙. `scene_prompt` · `SYSTEM_SCENE` 지우기 |
| `canon/pipeline.py` | `draft_stage(p, ep, event)`(`get_llm("plan")`), `extract_stage(p, ep, event)`(`get_llm("check")`), 둘 다 `stage.clean` 뒤 `pending.json` 에 남김. `apply_stage`(통째 적용, `prev` 에 이전 장면), `undo_stage`. `check_scene` 지우기 |
| `canon/web.py` | 작업 `stage_draft` · `stage_extract`(백그라운드), 적용 · 적용 취소 엔드포인트 |
| `canon/mock_stage.py` (새) | `@responds(StageDraft)` 가짜 응답, `mock.py` 끝에서 불러옴 |
| `canon/research.py` · `static/research.js` | `scene` 방식을 `stage` 로 |
| `canon/static/stage.js` | AI 버튼, 비교 보기(두 장면 평면도를 나란히, 박자 목록 차이), 적용 · 적용 취소 |

## 규칙

- `clean`: 모르는 인물 · 기준점 이름은 그 박자 `memo` 로, 본문에 없는 인용은 빈칸 + `stale` 표시, 막는 접촉은 빼고 수를 센다.
- 본문에서 뽑은 장면은 `basis` 에 본문 지문을 남긴다. 지금 본문과 다르면 화면이 '다시 뽑기'를 권한다.
- 이미 장면이 있으면 AI 결과는 덮지 않고 비교로만 보인다.

## 시험

- mock 으로 초안 · 추출 → `pending` → 적용 → 적용 취소.
- `clean` 이 미성년 성적 접촉을 뺀다(AI 가 냈다고 가정한 가짜 응답).
- 연구 검수 시험 `stage` 방식이 심은 동선 모순을 찾는다(mock).

## 확인하지 못할 것

실제 Gemini 호출의 추출 품질(키가 있을 때 연구 화면 검수 시험으로 잰다). 사용자가 할 단계: 실제 작품 한 화로 '본문에서 뽑기'를 돌려 평면도가 본문과 맞는지 본다.
