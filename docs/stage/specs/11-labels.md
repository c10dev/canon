# 11. 이름표 겹침 (평면도 · 3D)

상태: 구현 (2026-10-30, 설계도 같은 날 사용자와 정함) · 계획: [plan.md](../plan.md) 2차 · [references.md](../references.md) '손으로 그만 만들 것' 순위 4 · 먼저: 10 (같은 파일 `canon/static/stage.js` · `canon/static/stage3d.js` 를 고친다)

## 목표

장면 연출 평면도와 3D 보기에서 인물 이름표와 기준점 이름이 서로, 인물 원과 겹치지 않게 놓는다.

## 왜

- 평면도는 인물 이름표('하린 · 의자에 앉기')를 늘 원 바로 아래 32px 에 쓴다(`stgPlanSvg`). 두 사람이 0.5m 안에 서면 이름표가 겹쳐 읽을 수 없다. 2026-10-30 일감 10 화면 확인에서 '하린 · 의자에 앉기'와 '도윤 · 걷기'가 겹쳤다.
- 기준점 이름은 가구 가운데에 쓰고 인물 원 · 이름표를 비켜 가지 않는다.
- 3D 는 인물 이름표 높이를 출연진 순서로 세 칸 엇갈릴 뿐이다(`lift`). 카메라를 돌리면 다시 겹친다.
- three.js `CSS2DRenderer` 에는 겹침 정리가 없다. 지도 화면은 이미 같은 문제를 탐욕 배치 + 지시선으로 푼다(`atlas.js` `atlasLabels`).

## 정한 것 (2026-10-30 사용자)

| # | 물음 | 정함 |
|---|---|---|
| 1 | 범위 | 평면도와 3D 둘 다 |
| 2 | 놓는 법 | 화면 좌표에서 우선순위 탐욕 배치: 인물 이름표가 먼저(고른 인물이 맨 앞), 기준점 이름이 뒤. 인물 이름표는 원 둘레 여덟 자리 → 먼 고리 + 지시선 |
| 3 | 자리가 없을 때 | 인물 이름표는 자세를 떼고 이름만으로 다시 찾는다. 기준점 이름은 숨기고 마우스를 올리면(`<title>`) 보인다 |
| 4 | 재생 중 | 프레임마다 다시 놓되 앞 프레임 자리를 먼저 본다 |
| 5 | 코드 | `stage.js` 의 순수 함수 `stageLabelPlace` 하나를 평면도 · 3D 가 함께 쓴다(사용자에게 따로 묻지 않아 추천대로) |

## 놓는 법

1. 입력: 이름표마다 기준 점(화면 px), 글, 글자 크기, 우선순위, 줄일 글(자세를 뗀 이름). 먼저 차지한 상자(인물 원, 3D 는 없음)와 화면 범위.
2. 우선순위 높은 것부터 놓는다. 자리 후보: 아래 · 위 · 오른쪽 · 왼쪽 · 대각선 넷, 그다음 먼 고리(지시선).
3. 지난번에 놓은 자리(이름표 id 로 기억)를 맨 먼저 본다.
4. 다 막히면 줄일 글로 2 를 다시. 그래도 막히면 인물 이름표는 이름만으로 첫 자리(아래)에 겹쳐 두고, 기준점 이름은 숨긴다.
5. 글자 폭은 지도와 같은 어림(한글 1em, 나머지 0.6em, `stageTextW`). 3D 도 같은 어림에 이름표 안쪽 여백 12px 를 더한다(프레임마다 DOM 을 재지 않는다).

## 바꿀 곳

- `canon/static/stage.js`: `stageLabelPlace`, `stgPlanSvg` 의 인물 이름표 · 기준점 이름.
- `canon/static/stage3d.js`: `s3Pose` 뒤 · 카메라를 움직일 때 이름표 자리 다시 놓기, 이름표 안쪽 요소를 옮긴다(`CSS2DRenderer` 가 바깥 요소의 transform 을 덮으므로).
- 문서: `docs/stage/README.md` 정한 규칙, `plan.md`, `references.md`, AGENTS.md 의 `stage.js` 줄.

## 시험

- 겹치는 두 인물 이름표가 겹치지 않게 놓인다.
- 우선순위 높은 이름표는 첫 자리(아래)를 지킨다.
- 앞 자리를 주면 그 자리가 비어 있는 한 그대로다.
- 자리가 없으면 줄인 글을 쓰고, 기준점 이름은 숨는다.
- 평면도 화면에 이름표 상자가 서로 겹치지 않는다.

## 이번 범위 밖

- 지도 화면 이름표(`atlasLabels`)는 바꾸지 않는다.

## 구현 메모 (2026-10-30)

- 평면도: 기준점 이름은 기준점 `<g>` 에 `<title>` 로 늘 남고, 글은 인물 이름표를 놓은 뒤에 넣는다. 지시선 `stgLeader` 는 원 가장자리에서 이름표 상자의 가장 가까운 점까지.
- 3D: 이름표 바깥 div 는 `CSS2DRenderer` 가 옮기고, 안쪽 span 을 `s3PlaceTags` 가 옮긴다(배경도 span 에). 지시선은 캔버스 위 SVG 한 장(`s3.leaders`). `s3Draw` 마다(카메라를 움직일 때마다) 다시 놓는다. 예전의 높이 엇갈림(`lift`)은 뺐다.
- 시험: `tests/test_stage_labels.py`. 화면 확인은 mock 작품의 사무실 장면(평면도 · 3D 에서 '하린 · 의자에 앉기'와 '도윤 · 걷기'가 겹치지 않음, 하린 아래 '의자' 이름은 숨김).
