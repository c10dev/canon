# 머지 등급 정책

저장소 주인은 PR 을 하나씩 승인하지 않는다.
변경을 세 등급으로 나누고, 등급마다 누가 머지하는지 정한다.
등급을 가르는 경로 목록은 [merge-tiers.json](merge-tiers.json) 에 있다.
이 문서와 그 파일을 바꾸는 변경은 2등급이다.

## 등급

| 등급 | 뜻 | 머지 |
|---|---|---|
| 0 | 되돌릴 수 있는 내부 변경 | PR 을 연 세션이 CI 통과 뒤 머지한다 |
| 1 | 데이터 형식과 모듈 계약을 바꾸는 변경 | 독립 검수 흔적이 PR 에 있고 CI 가 통과하면 PR 을 연 세션이 머지한다 |
| 2 | 되돌리기 어렵거나 감시 장치를 바꾸는 변경 | 멈춘다. 저장소 주인이 승인한 뒤에만 머지한다 |

- PR 의 등급은 바뀐 파일 가운데 가장 높은 등급이다.
- 경로는 `fnmatch` 방식으로 견준다(`*` 가 `/` 도 넘는다).
- 목록에 없는 파일은 0등급이다.

## 2등급: 멈추고 승인받는다

- `merge-tiers.json` 의 `tier2.paths` 에 맞는 파일을 바꾼 PR.
- `tier2.deleted` 에 맞는 파일을 지운 PR(시험 파일 삭제).
- 경로와 상관없이 아래에 드는 변경.
  - 사용자 작품 데이터(`projects/`)를 지우거나 형식을 옮기는 코드
  - 기존 `project.json` 을 읽지 못하게 만드는 스키마 변경
  - AGENTS.md '설계 원칙 (깨지 않기)'에 어긋나는 변경
  - 승인 정책이나 권한 모드의 기본값을 느슨하게 만드는 변경
  - 시험을 건너뛰게 하거나(`skip` · `xfail` 추가) 단언을 지워 통과시키는 변경
  - 서버를 tailnet 밖에 여는 변경
  - 한 번에 $5 를 넘는 유료 호출을 기본 동작으로 만드는 변경
- 2등급 PR 을 연 세션은 머지하지 않는다. PR 본문 첫 줄에 `등급 2: <이유>` 를 적고 사용자에게 알린다.
- 사용자가 승인하면 세션은 PR 에 `작가 승인: <날짜>` 로 시작하는 댓글을 남기고 머지한다.
- 사용자가 승인하지 않은 2등급 PR 에 이 댓글을 달지 않는다.

## 1등급: 독립 검수 뒤 머지한다

- `merge-tiers.json` 의 `tier1.paths` 에 맞는 파일을 바꾼 PR.
- 검수는 그 변경을 쓰지 않은 새 컨텍스트의 세션이나 하위 에이전트가 한다.
- 검수자는 과제(명세나 PR 본문의 요약)와 diff 를 받는다. 구현 세션의 결론은 받지 않는다.
- 검수자는 두 가지를 본다: 과제의 요구를 구현했는가, 정확성 결함이 있는가. 모양은 보지 않는다.
- 검수자는 PR 에 `독립 검수: 통과` 나 `독립 검수: 문제 n건` 으로 시작하는 댓글을 남긴다.
- 문제가 있으면 구현 세션이 고치고 다시 검수받는다. 마지막 검수 댓글이 `통과` 일 때만 머지한다.

## 0등급: 게이트를 통과하면 머지한다

- PR 을 연 세션이 CI(`.github/workflows/test.yml`)가 통과한 것을 확인하고 머지한다.
- CI 가 끝나기 전에 머지하지 않는다. CI 가 실패한 PR 은 머지하지 않는다.
- 사용자에게 머지를 묻지 않는다. 건별 작업 보고도 보내지 않는다.

## 모든 등급에 걸친 규칙

- `main` 에 직접 푸시하지 않는다. 모든 변경은 PR 로 들어간다.
- 서버는 `main` 을 10분 안에 받는다. 머지는 곧 배포다([docs/server.md](../server.md)).
- 머지한 변경이 `main` 의 CI 를 깨면, 머지한 세션이 되돌리는 PR 을 먼저 연다. 되돌리는 PR 은 0등급이다.
- 등급을 판단하기 어려우면 높은 쪽으로 정한다.

## 지금 있는 장치와 없는 장치

- 있다: PR 마다 도는 전체 시험과 정적 검사.
- 없다: `main` 브랜치 보호. 이 정책은 세션이 지키는 약속이고, GitHub 가 막아 주지 않는다.
- 없다: 배포 뒤 자동 점검과 자동 되돌림.
- 없다: 주기적인 감사 세션.
- 저장소 밖의 일일 보고가 `main` 의 커밋을 이 정책과 견줘 어긋난 머지를 찾는다(PR 없는 커밋, 승인 댓글 없는 2등급, 검수 댓글 없는 1등급).
