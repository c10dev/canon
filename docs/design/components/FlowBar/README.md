# FlowBar

한 화를 쓰는 세 단계(집필 → 검수 → 상태 승인)를 보이는 띠로, 앱의 `flowBar(n, cur)`가 세 화면의 화 머리 바로 아래에 `<ol class="flow-bar">`로 그린다.

## 쓰는 법

- 앱이 만든다. 단계 글은 `flowSteps`가 정하고, 번호 · 이름은 사이드바 단계와 같다(4 집필 · 5 검수 · 6 상태 승인).
- 띠: 세 칸 같은 폭, `surface` 면, `line` 테두리, `radius-12`, 칸 사이 `line` 선.
- 칸(`.fl-cell`): 52px 이상, 번호 원(`.fl-n`, 24px) · 단계 이름(14px 700) · 한 줄 상태(`.fl-sub`, 12px `muted`, 넘치면 줄임표).
  - 지금 화면 칸은 `.cur`: `accent-soft` 면, 아래 3px `accent` 선, `aria-current="step"`. 번호 원은 `accent` 면에 `on-accent`.
  - 끝난 단계는 번호 대신 ✓, `green-soft` 면에 `green` 글자.
  - 갈 수 없는 단계(본문이 없어 검수 전 등)는 `.off`: 링크가 아닌 칸, `muted` 글자.
  - 주의할 상태 글은 `.fl-sub.warn`: `amber-ink` 700.
- 칸마다 `aria-label`에 '5단계 검수 (끝남): 지적 2개 남음'처럼 단계 · 끝남 · 상태를 함께 쓴다. 번호와 ✓는 `aria-hidden`.
- 640px 이하: 칸이 56px, 번호 원 20px, 번호 위 · 이름 아래로 가운데 정렬.
- 플롯이 초안인 화는 띠를 그리지 않는다.

## 지킬 것

- 단계 띠는 이동만 한다. 단계를 실행하는 버튼(`검수하기`, `반영`)은 머리 버튼 줄에 둔다.
- 고대비에서는 지금 칸에 `Highlight` 테두리를 그린다.
