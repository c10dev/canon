# Toast

동작의 결과를 잠깐 알리는 말풍선으로, 앱의 `toast(msg, err, opt)`가 알림 버튼 바로 아래 `#toast`에 붙이고 알림 창의 '최근 알림'에 남긴다.

## 쓰는 법

- 앱이 만든다: `toast("저장했어요")`, 오류는 `toast(msg, true)`.
- 보통 알림은 `inverse-bg` 면 · `inverse-ink` 글자, 3.5초 뒤 사라진다.
- 오류는 `red` 면이고 읽을 때까지 남는다. 닫기 버튼(`✕`, `aria-label="닫기"`, 32px, 손가락 기기 44px)이 붙는다.
- 오류에 할 일이 있으면 버튼을 붙인다: `toast(msg, true, { actions: [{ label: "다시 시도", run }] })`. 버튼은 `.btn.small.t-act`(36px, 손가락 기기 44px), 테두리는 글자색, 면 없음. 누르면 말풍선을 닫고 할 일을 한다. AI 작업 실패는 `다시 시도`와, API 키 · 연결 오류면 `설정`을 붙인다.
- 자리(`hub.js` `placeHub`): 알림 버튼 바로 아래 8px. 폭 360px이고, 오른쪽 끝을 버튼 오른쪽 끝에 맞추되 화면 왼쪽 14px 밖으로 나가지 않는다. 휴대폰 폭(640px 이하)은 좌우 16px. 버튼이 화면 밖이면 화면 맨 위 8px, 왼쪽 16px. 알림 창이 열린 동안은 숨긴다.
- 글자 13px, 줄 간격 1.5, 모서리 `radius-10`, `shadow-toast`.
- 되돌리기 말풍선: 상태 승인에서 반영한 직후 `n화를 반영했어요` + `되돌리기`(`.btn.small`) + 닫기를 띄운다(`review.js` `rvUndoShow`). 10초 뒤 사라지고, 마우스를 올리거나 포커스가 안에 있는 동안은 남는다. 버튼과 닫기는 40px다.

## 지킬 것

- 결과를 과거형 해요체로 쓴다: "저장했어요", "작품을 지웠어요. 서버의 projects/.trash에 남아 있어요".
- 많이 쌓이면 오래된 알림부터 내린다. 오류는 알림이 밀어내지 않는다. 한 번에 보통 알림은 셋, 오류는 다섯까지.
- 내린 알림도 알림 창의 기록(최근 60개)에서 다시 본다. 기록은 브라우저를 새로 고치면 지운다.
- 화면 아래에 따로 알림을 띄우지 않는다. 화면 아래는 저장 띠와 반영 줄의 자리다.
- 미리보기는 알림을 제자리(static)에 그린다.
