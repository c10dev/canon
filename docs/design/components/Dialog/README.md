# Dialog

지금 화면 위에 뜨는 대화상자로, `<dialog>`를 `showModal()`로 연다. 공통 대화상자는 앱의 `showDialog(id, html, back)`, 설정은 `openSettings`가 연다.

## 쓰는 법

- 쓰는 쪽이 줄 것: 대화상자 id, 제목(`<h2 id="<id>-title">`, 대화상자의 `aria-labelledby`), 내용, 아래 버튼 줄(`.row`, 주 버튼 오른쪽 끝).
- 공통 대화상자(`dialog.w-dialog`): 폭 `min(560px, 100vw - 32px)`, 높이는 화면 높이 - 48px까지, 안쪽 `space-20` · `space-24`, `surface` 면, `line` 테두리, `radius-12`, `shadow-dialog`. 배경(`::backdrop`)은 `overlay`.
- 설정 대화상자(`dialog.set-dlg`): `min(980px, 100vw - 48px)` × `min(760px, 100vh - 48px)`, `bg` 면, `radius-12`.
  - 왼쪽 갈래 목록(`.set-nav`, 240px, `surface` 면): 제목, 찾기 칸, 갈래 이름(이 컴퓨터 · 이 작품 · 이 브라우저), 갈래 줄 38px. 지금 갈래는 `btn` 면 700.
  - 오른쪽 내용(`.set-main`, 최대 720px): 구역마다 `h3` 제목과 줄 묶음(`.set-rows`: `surface` 면, `line` 테두리, `radius-12`).
  - 줄(`.set-row`): 64px 이상, 왼쪽 이름 · 설명, 오른쪽 조작(입력칸 · 나눔 버튼 · 스위치). 줄 사이는 `rule` 선. 바꾸면 바로 저장하고 줄 안에 결과를 짧게 쓴다(`.set-note`). 저장 띠를 쓰지 않는다.
  - 640px 이하는 화면 전체를 덮는다. 갈래 목록이 먼저 보이고, 누르면 그 갈래 상세로 넘어간다(`‹ 설정` 버튼으로 돌아감).
- 스킬 도감 카드(`#ab-pop`, 상태창 조각 칩을 누르면 뜬다)도 공통 대화상자다. 머리는 `h2` 이름과 등급 칩, 오른쪽에 44px 닫기(✕) 버튼이고, 아래 버튼 줄(`.dlg-foot`)은 오른쪽에 맞춘다.
- 확인 대화상자(`#ask-dlg`)는 브라우저 `confirm` · `prompt` 대신 쓴다. 앱의 `askConfirm(글, 옵션)`은 고르면 true, `askText(글, 옵션)`은 적은 글을 돌려준다.
- 확인 대화상자의 제목은 `h2`다. 옵션 `title`이 없으면 글의 첫 문단에서 첫 물음(…까요?)까지를 제목으로 쓴다.
- 확인 대화상자의 나머지 글은 줄마다 문단 하나다.
- 확인 대화상자의 버튼 줄(`.row.dlg-foot`)은 오른쪽에 맞춘다: [취소] [주 버튼].
- 확인 대화상자의 주 버튼 글자는 물음의 동사다(`지우기`, `버리기`, `바꾸기`, `되돌리기`, `멈추기`). 기본 글자는 `확인`이다.
- 지우기 · 버리기 · 덮어쓰기처럼 되돌리기 어려운 동작은 주 버튼을 `.btn.danger`로 쓴다(옵션 `danger`).
- 주 버튼이 '…취소'(`반영 취소`, `적용 취소`)이면 취소 버튼은 `닫기`다.
- 글을 받는 확인 대화상자(`askText`)는 버튼 줄 위에 입력칸 하나를 둔다. 이름은 옵션 `label`이고, 없으면 제목이 이름이다.
- 입력칸에서 Enter는 주 버튼과 같다.
- 열면 입력칸에, 입력칸이 없으면 주 버튼에 포커스를 둔다.
- Esc · 바깥 누르기 · 취소 버튼은 취소다(`askConfirm`은 false, `askText`는 null).
- 확인 대화상자가 열린 동안 키는 뒤 화면의 단축키와 Esc 처리에 닿지 않는다.
- 확인 대화상자가 열린 채로 또 물으면 앞 물음은 취소로 끝나고 같은 대화상자에 새 물음을 채운다.
- 확인 대화상자만 다른 대화상자 위에 뜰 수 있다(설정 · 스킬 도감 카드 안의 지우기 확인).
- 페이지를 닫을 때의 경고(`beforeunload`)는 브라우저가 띄우는 창이라 그대로 둔다.
- 명령 팔레트(`.pal`)는 `<dialog>`가 아니라 덮개(`.pal-back`) 위의 칸이다. 폭 560px, 화면 위 12vh, `line-strong` 테두리, `radius-12`, `shadow-dialog`.

## 지킬 것

- 바깥(배경) 누르기 · Esc · 닫기 버튼으로 닫는다. 닫으면 연 버튼으로 포커스를 돌린다. 연 버튼이 사라졌으면(메뉴 항목) `back` 선택자로 찾은 곳으로.
- 화면을 다시 그려도 열린 대화상자는 그대로 둔다. 다시 채울 때 고치던 칸의 포커스를 남긴다.
- 브라우저 `confirm` · `prompt`를 쓰지 않는다(`tests/test_ask_js.py`).
- 고치는 칸을 대화상자로 빼지 않는다. 대화상자는 설정, 확인, 내려받기처럼 화면 밖의 일에 쓴다(Card의 '읽기 카드와 고치기 카드').
- 대화상자 위에 대화상자를 겹쳐 열지 않는다. 확인 대화상자만 예외다.
