# Empty

아직 내용이 없는 자리에 두는 빈 화면으로, `<div class="empty">`에 이유 한 문장과 다음 동작 버튼 하나를 둔다.

## 쓰는 법

- 쓰는 쪽이 줄 것: 왜 비었는지 한 문장, 그 자리를 채우는 주 버튼 하나(`.btn.primary`, 가는 곳이면 `<a class="btn primary">`).
- 가운데 정렬, 안쪽 40px · `space-24`, 묶음 사이 `space-14`, 글자 `muted`.

## 지킬 것

- 빈 화면은 막힌 이유와 풀 길을 함께 보인다: "3화 플롯이 아직 초안이에요. 확정해야 쓸 수 있어요." + `3화 플롯 확정하러 가기`.
- 버튼은 하나만 둔다.
