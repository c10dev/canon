# Busy

AI 작업이 도는 동안의 표시다. 버튼 글자를 바꾸는 것, 머리의 진행 줄, 화면 전체 가림막 세 가지가 있다.

## 쓰는 법

- 버튼(앱의 `jobBtn(kind, ep, idle)`): 작업을 부르는 버튼은 이 함수가 돌려준 글자와 속성을 쓴다.
  - 누른 뒤 서버가 받기 전: `<원래 글자> · 시작하는 중…`.
  - 작업이 도는 동안: `<작업 이름> 만드는 중…`, 여러 개를 만들면 `3/10`처럼 진행 수를 붙인다.
  - 두 경우 모두 `aria-disabled="true"` · `aria-busy="true"`를 단다. 보기는 쓸 수 없는 버튼(불투명도 0.5)과 같다.
- 진행 줄(`.w-busy`, 집필 화면 `wsBusy`): 본문이 없는 화에서 머리 주 버튼 자리를 대신한다. `sel-bg` 면, `sel-line` 테두리, `radius-10`. 안에 `<작업> 만드는 중`(굵게) · 경과 시간(1초마다 고침) · 4px 줄무늬 막대(`accent` · `chip`, 1.2초에 한 바퀴) · `멈추기` 작은 버튼. `role="status"`.
- 돌아가는 표시(`.spinner`): 22px, 작은 것 16px · 14px. `accent-soft` 테에 `accent` 윗변. 알림 버튼 · 사이드바 배지 · 카드 안 짧은 기다림에 쓴다.
- 가림막(`#busy`, `.busy-box`): 화면 전체를 `overlay`로 덮고 가운데 상자(`surface`, `radius-12`, 최대 360px)에 돌아가는 표시와 글, 필요하면 `멈추기`. 다른 조작을 막아야 하는 짧은 일에만 쓴다.

## 지킬 것

- 경과 시간은 낭독하지 않는다(`aria-hidden`). 1초마다 바뀌어 낭독 영역 안에 두면 낭독기가 매초 읽는다. 가림막 상자는 작업 이름만 이름으로 읽힌다(`aria-labelledby`).
- 작업 중인 버튼에 `disabled`를 쓰지 않는다. `disabled`는 포커스를 잃게 해서 키보드 사용자가 문서 처음으로 돌아간다.
- 오래 걸리는 AI 작업은 가림막으로 화면을 막지 않는다. 알림 버튼에 모으고 버튼 글자 · 진행 줄로 보인다.
- 움직임은 `prefers-reduced-motion`에서 멈추거나 느려진다(진행 줄 막대는 멈추고, 돌아가는 표시는 3초에 한 바퀴).
- 작업이 끝나면 결과를 말풍선(Toast)과 알림 창에 남긴다.
