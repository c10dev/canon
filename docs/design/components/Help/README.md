# Help

늘 보일 필요 없는 설명을 누르면 펼치는 물음표 툴팁이다. 앱의 `help(text)` 가 그린다.

## 쓰는 법

- 쓰는 쪽이 줄 것: 해요체 설명 한두 문장. 버튼 이름이 다르면 둘째 인자(기본 `설명 보기`).
- 설명 줄 · 입력칸 이름 · 제목 바로 뒤에 붙인다. `input()` 은 `help` 옵션으로 이름 뒤에 붙인다.
- 숫자로 된 판정 기준(30% 넘게, 5건부터)은 여기에 둔다. 늘 보이는 글에는 무엇을 알려 주는지만 쓴다.
- 모양: 18px 원 버튼에 `?`, `surface` 면, `line-strong` 테두리, `text-2` 글자(11px, 700).
- 열린 버튼은 `accent-soft` 면 · `accent-ink` 글자 · `accent` 테두리다(`aria-expanded="true"`).
- 펼친 글은 버튼 아래 6px 에 뜬다: `surface` 면, `line` 테두리, `radius-8`, `shadow-float`, 13px · 줄 간격 1.55, 폭 300px 까지(`--z-pop`).
- 오른쪽 끝에서 넘치면 버튼 오른쪽에 맞춰 왼쪽으로 펼친다(`.help-pop.end`).
- 한 번에 하나만 열린다. 바깥을 누르거나 Esc 를 누르면 닫히고, Esc 는 포커스를 버튼으로 돌린다.
- 손가락 기기 · 640px 이하에서는 모양을 두고 누름 영역만 44px(`touch-min`)로 넓힌다.

## 지킬 것

- 툴팁에만 둔 글이 없으면 잘못 쓰게 되는 내용이면 툴팁에 넣지 않는다. 늘 보이는 줄에 둔다.
- 같은 설명을 늘 보이는 줄과 툴팁에 함께 쓰지 않는다.
- `title` 속성은 손가락 기기에서 보이지 않는다. 읽혀야 하는 설명은 `title` 대신 이 툴팁을 쓴다.
